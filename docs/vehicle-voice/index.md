# 车载语音专题

车载语音专题分为开发和测试两条独立内容线。开发文档讲如何构建语音算法、服务和车机功能；测试文档讲如何验证系统链路、质量指标和业务结果。两条路线各有自己的目录、学习计划和专题文档。

| 内容线 | 学习目标 | 入口 |
|---|---|---|
| 开发 | 从数字音频、DSP 和语音算法基础走到车机集成与端侧部署，形成可运行的软件或模型产物 | [开发学习路线](/vehicle-voice/development/roadmap) · [开发知识点目录](/vehicle-voice/development/) |
| 测试 | 从语音输入、算法评估走到设备集成、业务断言和回归闭环，形成可复现的测试与质量证据 | [测试专题导览](/vehicle-voice/testing/) · [测试学习路线](/vehicle-voice/testing/roadmap) |

开发专题位于 `development/`，测试专题位于 `testing/`。各自文档保持独立；通用编程、Linux、Python、数据治理和 CI 能力可按需复用。
