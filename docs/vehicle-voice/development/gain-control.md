# 自动增益控制（AGC）

## 作用

自动增益控制（Automatic Gain Control, AGC）让不同距离、音量和麦克风灵敏度下的语音幅度保持在可处理范围。AGC 处理的是幅度动态范围，不会改善信噪比；把噪声一并放大是常见副作用。

## 关键参数

目标电平、最大/最小增益、attack（增益下降速度）、release（增益恢复速度）、门限和 limiter（限幅器）共同决定响应。attack 太慢会让大声瞬态削波，太快可能压扁语音；release 太快会把句间噪声抬高，太慢则使轻声起始被压低。

## 系统位置

记录 AGC 前后的增益轨迹，说明它位于 AEC、降噪和特征提取的哪个位置。多麦克风波束形成后再做统一增益，还是各通道先独立调节，需要按阵列算法设计决定；各阶段的增益变化必须可追踪。

## 练习与验收

输入从轻声到大声的阶梯信号、突发峰值和静音噪声。测量输出电平、削波比例、噪声底和响度恢复曲线。验收时设置峰值保护，并确保静音段不会被无界放大。

## AGC 参数实验

构造从轻声到大声的分级输入、突发峰值、静音背景和远场语音，逐项调整目标电平、增益上下限、attack/release 与 limiter。保存增益轨迹、输入输出 RMS/峰值和削波比例；同时观察静音段噪声是否被抬高。

明确 AGC 相对波束形成、AEC、降噪和特征提取的位置；多通道独立增益可能破坏相位/空间信息，必须按链路设计验证。归一化算法也不能被误当成 SNR 改善。

**验收产物：**不同响度下的输出电平分布、增益恢复曲线、噪声底和语音清晰度对照；上限保护、静音门控和异常输入行为应有确定结果。
