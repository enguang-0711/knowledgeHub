# Python 音频数据处理

Python 适合语料处理、实验、训练、评估和可视化。音频开发脚本必须严谨处理采样率、样本数、通道、数值范围和时间戳。

## 波形数组

波形通常是一维单声道或形如 `[samples, channels]` 的数组，也可能是 `[channels, samples]`。记录 shape、dtype、端序和幅度范围。整数 PCM 转浮点需要按编码范围缩放；简单转换 dtype 不会自动归一化。双声道平均成单声道会丢失空间信息，不可用于阵列/音区算法回归。

## 文件读写与重采样

检查容器、编码、采样率、声道、位深和时长，不能只根据扩展名判断。改变采样率必须执行重采样滤波并生成新资产，不能只改文件头。重采样需考虑抗混叠、滤波延迟和边界处理；新旧数据的父哈希和工具参数应记录。

## 分帧、特征和批处理

理解帧长、帧移、窗函数、补零和尾部处理。声谱图需明确 FFT 点数、频率轴、功率/幅度、log 底数和归一化。批处理时保留样本 ID 与特征对应关系，异常音频要记录跳过原因。

## 可靠实验脚本

数据读取、变换、评估和报告分层；参数通过命令行或配置输入；输出包括运行版本、样本数、失败样本和文件哈希。使用固定随机种子时也记录库版本，因为不同实现仍可能造成数值差异。

## 练习与完成标准

实现音频清单检查器，校验解码、采样率、声道、位深、峰值、静音、NaN/Inf、时长和哈希；再实现重采样与 STFT 可视化。对同一输入两次运行应得到一致元数据和可解释的数值结果。
