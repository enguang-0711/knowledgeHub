# 车内声学与音频前端

语音系统接收到的是扬声器、车厢和麦克风共同形成的信号。远场、混响、噪声和多通道布局会影响唤醒、识别和音区判断。

## 声学链路

考虑声源位置、扬声器频响和指向性、车厢反射、座位/玻璃/内饰、麦克风频响/灵敏度、阵列间距及安装遮挡。播放器音量不是声压级；用参考麦克风或校准链路测量实际声压和背景噪声。

声学反射形成直达声和延迟回声。座舱噪声可能平稳（空调/胎噪）也可能瞬态（鸣笛、敲击、乘员说话），不同频谱和时序的噪声即使 SNR 相同，对识别影响也不同。

## 音区和远场

多麦克风系统可利用空间差异增强目标方向语音或区分音区。阵列几何、同步、通道增益/相位一致性和车内反射会影响方向估计。阵列通道必须按物理位置固定顺序；通道交换会改变算法意义。

远场语音声压更低、混响比例更高。前端应处理动态范围与回声，但过强降噪可能损坏辅音、词尾或低能量语音。

## 工程设计和测量

固定车厢配置、座椅位置、窗户、空调、媒体状态、播放位置和麦克风位置；记录校准设备、增益和噪声来源。同步保存播放参考与采集回采，用波形和频谱确认输入是否实际到达。声音条件应描述位置、频谱/来源和时间变化，而不只记录单一 SNR。

## 练习与完成标准

比较近场/远场、静音/空调噪声、单声道/多通道录音；计算 RMS、峰值、SNR 的定义值并绘制频谱。用回采检查播放增益与声源位置变化，记录哪些条件会影响前端输入。
