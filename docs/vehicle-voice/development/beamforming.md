# 麦克风阵列与波束形成

## 基本原理

波束形成利用多个麦克风的空间差异增强目标方向声音并抑制其他方向噪声。延时求和通过补偿到达时间差后叠加通道；自适应方法会根据目标与干扰估计调整权重，空间选择性更强，但对阵列模型和信号条件更敏感。

## 几何和同步

阵元位置、通道映射、极性、增益和采样同步决定空间相位关系。声速随温度变化，安装偏差、壳体遮挡和车内反射会造成模型失配。阵列配置与实际麦克风布局必须使用同一坐标约定并纳入版本管理。

## 工程调试

采集逐通道同步样本，先检查通道间时延、幅度和极性，再验证不同方位的波束图。用真实座舱录音检查目标方向语音、非目标说话人、空调/路噪和混响下的效果。不要仅靠理想仿真证明车内效果。

## 练习与验收

用双麦克风录制多个方向的语音与噪声，计算通道互相关并实现基础延时求和。报告各角度信噪比变化、语音失真和阵元异常时的降级行为。
