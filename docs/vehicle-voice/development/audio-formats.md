# 语音数字音频格式

## 数据表示

PCM 将采样幅值表示为整数或浮点数。音频接口需明确采样率、位深/数据类型、端序、声道数、交错布局、帧长和时间戳。采样率决定可表示频率范围，位深影响量化动态范围；错误解释格式会造成噪声、变速或声道串扰。

## 电平和边界

归一化浮点 PCM 通常采用约定幅度范围，整数 PCM 受满量程约束。检查峰值、RMS、静音、削波和 NaN/Inf；dBFS 参考数字满量程，不能无校准地换算为 dB SPL。

## 文件和转换

读取 WAV 时验证容器元信息和实际样本数。重采样需真正执行滤波和采样变换，不能只改 header；混音、通道选择和格式量化要记录参数并保存源文件。

## 练习与验收

生成已知频率正弦波，写入不同采样率/位深 WAV，读取后验证时长、峰值和主频。故意错配采样率，观察并解释变速和音高变化。
