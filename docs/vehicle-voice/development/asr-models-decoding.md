# ASR 模型与解码

自动语音识别（ASR）把音频或声学特征映射为文本。现代系统可能是端到端模型，也可能组合声学模型、发音词典和语言模型；流式与离线架构对延迟和解码策略的要求不同。

## 建模概念

- **声学特征：**波形经过分帧、谱变换和特征归一化，供模型提取语音表征。
- **CTC：**通过 blank 和路径折叠对齐输入帧与较短文本序列，支持相对简单的单调对齐；输出重复字符和 blank 的折叠规则很重要。
- **RNN-T：**联合声学时间步和已输出 token 状态，常用于流式识别；预测网络和搜索会影响延迟/内存。
- **Attention/Encoder-Decoder：**通过注意力对输入序列进行条件解码；流式能力取决于编码器可见上下文和缓存策略。
- **语言模型/词典：**可用于候选约束、热词或领域偏置；偏置强度过高可能引入不在音频中的词。

以上是模型家族的概念对比，具体实现差异依模型、训练目标和运行时而定。

## 解码与文本输出

贪心解码计算简单，beam search 搜索多个候选但成本更高。语言模型融合、热词、标点恢复、数字规范化和分词会影响最终文本。保留原始 token/文本及后处理结果，才能区分声学识别与文本转换错误。

流式识别会输出 partial 和 final；partial 可能被修订。定义稳定前缀、更新策略、final 条件和时间戳语义。首个 partial 延迟与最终结果延迟是不同指标。

## 调试路径

先确认输入音频与特征，再看模型 logits/置信度和候选序列，最后检查解码、热词和文本归一。若有时间戳，确认其对应音频采集时钟而非消息到达时钟。

## 练习与完成标准

对固定音频比较两个解码配置或热词配置，保留逐样本候选、最终文本和时延。选择含近音词、数字和否定词的样例，判断错误来自模型还是解码/归一化。报告明确指出模型与解码器版本。
