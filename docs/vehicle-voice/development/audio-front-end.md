# 语音前端算法导航

音频前端由目标不同的算法模块组成，需分别理解输入参考、输出信号和评价方法：

- [声学回声消除 AEC](./echo-cancellation)：抑制扬声器回灌到麦克风的回声。
- [语音降噪 NS](./noise-reduction)：抑制背景噪声并保护语音细节。
- [自动增益控制 AGC](./gain-control)：管理信号幅度与动态范围。
- [麦克风阵列与波束形成](./beamforming)：利用空间信息增强目标方向。

组合系统中还要验证模块顺序、同步和增益位置；[音频前端总览](./acoustics-audio-front-end)介绍车内声学背景。
