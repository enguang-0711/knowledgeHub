# 语音端点检测

## 作用

端点检测判定一段用户话语何时结束并可以提交最终识别。端点太早会截断尾词，太晚会增加响应时间并保留不必要音频。它通常联合 VAD 状态、静音持续时间、识别器 partial 稳定度和产品交互规则。

## 状态机设计

典型状态包括等待语音、语音中、疑似结束、已提交和取消。短停顿可继续累积；超过静音门限后提交；达到最大话语时长应分段或安全结束。唤醒、按键、打断和网络中断会改变状态转换，因此应明确优先级和可重复事件行为。

## 调试与指标

为音频帧、VAD 变化、partial/final 结果和提交事件使用同一单调时钟。报告端点延迟、尾部截断率、误提前结束率和超时率。按句间停顿、犹豫、数字串和车载噪声切片，才能解释阈值为何有效或失效。

## 练习与验收

实现有限状态机并回放有短停顿、长停顿、改口、持续噪声和达到时长上限的录音。为每次提交输出可追踪原因，确保重连和会话取消不会提交旧缓冲。

## 端点状态机的实现核对

为等待语音、语音中、疑似结束、已提交、取消和超时定义进入/退出条件，明确 VAD 门限、静音持续时间、partial 稳定规则、最大话语长度和重新打开窗口。短停顿、犹豫、数字串和句中呼吸需要与真正结束区分。

每个输入帧、partial 更新和 final 提交使用单调时钟与会话 ID 记录；重复回调必须幂等。网络断开、用户打断、再次唤醒和设备重连时清理或保留缓冲的行为要写入状态转移表。

**验收产物：**状态转移日志、尾词截断/提前提交/端点延迟统计和边界录音；超时后不得把旧缓冲拼入下一会话。
