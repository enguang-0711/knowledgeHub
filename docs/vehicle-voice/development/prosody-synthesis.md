# TTS 韵律与语音合成

## 合成链路

现代 TTS 常由文本/音素编码、时长与韵律预测、声学表示生成和声码器组成；产品还包括分句、流式传输、音频混音和播放控制。错误可能来自文本前端、发音、时长/音高预测、声学模型或播放时钟。

## 韵律

韵律包括停顿、重音、语速、音高和语气。导航提示、状态播报和错误说明对可懂度、紧迫感和打断性有不同要求。长句应按语义切分，数字和单位应连续朗读，不能只追求自然度分数。

## 流式与资源

流式合成需要定义首包、分句、音频格式、取消和播放完成事件。新会话或用户打断时要停止旧流并释放缓存；采样率、声道和播放缓冲必须与音频服务匹配。

## 练习与验收

为状态查询和导航播报准备长短句，检查专有名词发音、数字韵律、首音延迟、分句自然度、取消和播放完成。结合主观听测与自动化事件记录评价。

## TTS 韵律链路调试

把文本归一/分句、G2P/词典、韵律预测、声学模型和声码器分别观测；保存输入文本、音素/韵律中间表示、音频格式和推理版本。数字、英文、专名、标点和长句先检查文本前端，再判断韵律或声学模型。

评估停顿位置、重音、语速、音高、响度、发音清晰度、主观自然度和首包/整句时延。流式合成还需测试块拼接、首尾静音与中断续播；高自然度但慢启动未必符合车载对话预算。

**验收产物：**固定文本集试听清单、参数/音色版本、客观声学统计、主观评审规则和延迟分布；真人/合成音频分别标注，不能用 TTS 回归代替真人语音覆盖。
