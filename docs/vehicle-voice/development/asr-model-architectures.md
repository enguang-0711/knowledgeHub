# ASR 声学模型架构

## 序列建模

ASR 将变长声学帧映射为文本 token。CTC 用 blank 和单调对齐简化训练/解码；RNN-T 通过预测网络建模历史输出，适合流式逐步识别；Attention encoder-decoder 通过注意力对齐输入输出，常用于非流式或分块架构。

## 选型维度

评估语言与词表、流式需求、首字延迟、准确率、训练数据、端侧算力、运行时支持和维护成本。架构名不保证产品特征；实际流式行为还取决于分块、缓存、解码和端点策略。

## 训练和部署关联

输入特征、tokenizer、模型输出和解码器必须一致。部署前冻结特征配置、模型格式、上下文长度和动态状态，验证端侧数值与输出对齐。

## 练习与验收

使用公开实现比较一种离线模型和一种流式模型，观察 partial 输出、延迟、错误类型和资源。明确实验数据与解码配置，避免只比较论文指标。
