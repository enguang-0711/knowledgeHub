# 说话人归属与区分

## 任务边界

说话人归属可能指声源定位、当前发言人区分或说话人分离，三者输出和用途不同。车载助手应只实现产品需要的能力，并明确是否使用匿名短时特征，避免把说话人区分误当成可靠身份认证。

## 数据与算法因素

声道几何、混响、说话距离、重叠语音、口罩/姿势和个体差异都会影响归属。评估集应包含多人轮流/同时讲话、跨座位移动和无目标语音，并按会话隔离。

## 隐私和状态

说话人特征可能属于敏感信息。限定用途、保存周期和处理位置；会话关闭或用户切换时清除不必要的临时状态。对不确定结果保留拒识能力。

## 练习与验收

用左右座位和重叠说话样本比较区域分类与说话人区分输出。报告混淆矩阵、拒识比例和场景限制，并确认日志不保存长期身份模板。

## 说话人归属的端到端核对

区分说话人分离、说话人识别和音区归属：它们使用的标签与错误含义不同。标注说话人片段起止、重叠语音、远近场和未知说话人；算法输出需附时间段、置信度和拒识结果，不能强制归到已知成员。

将归属结果与麦克风阵列/座位音区、ASR 文本和会话 ID 对齐，检查交叉说话、短语、静音间隔和多人同时说话。新行程/新会话边界应清除不该持久化的声纹状态。

**验收产物：**DER/归属准确度等明确口径、按重叠/噪声/距离切片的错例，以及错误归属对下游个性化命令的影响分析。
