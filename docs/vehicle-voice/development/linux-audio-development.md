# Linux 音频开发环境

## 必备能力

掌握进程/线程、权限、文件与设备节点、动态库、环境变量、信号和系统服务。音频研发常需检查声卡/PCM 设备、采集与播放权限、设备路由、时钟和内核/用户态接口；具体命令随平台和 Android/Linux 发行版变化。

## 构建与运行

建立可重复的 CMake/构建脚本，区分交叉编译工具链、目标 ABI、sysroot 和运行时动态库。部署前检查架构、依赖版本、文件权限和模型/词典路径。生产设备调试需遵循项目授权，不绕过平台安全机制。

## 常见问题

设备打开失败可能来自权限、占用或路由；运行时库错误可能来自 ABI/版本不匹配；录音无声需同时核对设备选择、增益、时钟和数据格式。记录完整命令、环境和版本，避免“本机可用”结论。

## 练习与验收

在开发机查看音频设备，采集或回放一段测试信号，检查权限、采样格式和进程资源。将程序放入干净目标环境，按 README 完成安装和诊断。
