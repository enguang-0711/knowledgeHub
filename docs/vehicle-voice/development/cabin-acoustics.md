# 车内声学

## 声学环境

车厢内直达声与玻璃/内饰反射共同形成混响；空调、轮胎、风噪和媒体声具有不同的频谱与时间特性。说话距离、朝向、座位和车窗状态改变麦克风接收到的 SNR 与混响比例。

## 测量与建模

固定座位、麦克风/扬声器位置、车辆状态、音量和环境条件。分别记录语音段、噪声段、背景声类型和测量位置。播放器音量不是声压级；SPL 测量需要校准麦克风，数字 dBFS 不能直接视为 dB SPL。

## 对语音系统的影响

远场导致语音更弱且混响更显著，瞬态噪声会影响唤醒/VAD，稳定噪声会影响降噪和 ASR。相同平均 SNR 的音乐、风噪和多人说话对识别的影响可能完全不同，因此要按声源和座舱状态切片。

## 练习与验收

设计近场/远场、空调开关和媒体播放场景，记录条件并采集同步参考音频。提交可复现的场景表、校准说明和对识别输出的分层比较。
