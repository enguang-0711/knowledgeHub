# TTS 文本规范化

## 目标

文本规范化把数字、日期、单位、缩写、符号和混合语言文本转为适合朗读的形式。显示文本与播报文本可能不同，二者应分别保存以支持界面展示、语音合成和日志审计。

## 规则设计

规则应使用明确的上下文和类型识别，例如“12:30”可能表示时间，“12 km”表示距离，“3/4”可能表示分数或日期。按领域维护单位、车辆状态、品牌名和地名词典；无法确定的形式应回退或向上游请求澄清。

## 工程注意

规范化规则需要有版本、优先级和可解释输出。避免全局替换、重复转换和地区格式假设。语音合成前后的文本、音素/发音结果及规则命中记录可帮助定位误读。

## 练习与验收

编写覆盖车速、温度、时间、续航、电话号和媒体名的规范化样例。对每条输入保留预期朗读形式，并对未知格式、空值和混合语言做回归。
