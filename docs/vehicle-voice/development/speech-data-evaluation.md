# 语音数据集与评估

语音模型的训练和评估依赖规范化音频、可信转写和独立切分。指标只有在文本规则、样本范围和分母明确时才可比较。

## 语料资产管理

将原始录音视为不可变资产；处理/重采样/降噪后的音频作为派生版本，保存父哈希、工具和参数。manifest 建议包括样本 ID、音频 URI/哈希、采样率、声道、时长、参考文本、语言/口音、录制设备、噪声条件、说话人授权、意图/槽位标签、用途许可和数据切分。

训练、验证和测试集按说话人、行程、设备或采集批次隔离。固定测试集不得用于反复调参；必要时维护滚动回归集并记录每次变更。

## 转写和归一化

保留原始转写与规范化转写。规则需要定义标点、数字、单位、英文/中文混写、填充词、口语变体和不可辨片段。WER/CER 对归一化和分词策略敏感，报告应保存 normalizer/tokenizer 版本。

WER 基于替换、删除、插入总数除以参考词数；CER 使用字符为单位。不同系统的分词和文本处理不同，直接比较总分可能失真。保留逐样本错误类型，并对关键实体、数字、否定和槽位相关词单独切片。

## 评估维度

除了 WER/CER，还应关注句准确率、关键词/实体召回、拒识、唤醒/端点、partial 稳定性和时延。时延定义起止事件和时钟；流式首字、最终文本、语义结果和业务执行各有不同边界。样本量小或类别不平衡时，报告样本数并谨慎解释差异。

## 练习与完成标准

构建音频/文本 manifest 和归一化脚本；用小型人工核验集计算 WER/CER，并输出每样本 S/D/I 错误。对比两种归一规则，说明分数变化是识别改进还是评估口径变化。
