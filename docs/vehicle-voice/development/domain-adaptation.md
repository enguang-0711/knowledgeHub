# 车载语音领域适配

## 为什么需要适配

通用 ASR 常在车载专有名词、品牌/地名、口语指令、车内噪声、远场和特定麦克风上出现分布偏移。适配应先区分词汇覆盖、声学失配、语言风格和解码偏置，再选择最小有效措施。

## 常见手段

可补充领域文本或热词，调整语言模型/词典；用少量目标域音频做微调或 adapter；改善前端和数据增强；对热词设置上下文偏置。热词偏置过强会带来误插词，微调数据过少则容易遗忘通用能力。

## 评估策略

建立目标域固定集和通用能力保护集，分别评估专有词召回、整体 WER/CER、误插、延迟和资源。比较适配前后逐样本差异，并按实体类别、说话人、噪声和句长切片。若只在训练近似句上变好，不能证明泛化。

## 练习与验收

为一组车机媒体名/导航地名构建目标域小集和泛化保护集，比较热词、数据微调两种方案。给出性能收益、回退风险、模型版本与撤回方案。
