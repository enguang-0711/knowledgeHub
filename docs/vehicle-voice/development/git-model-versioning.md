# 语音代码与模型版本管理

## 版本边界

Git 适合管理源码、接口 schema、配置模板和小型测试资产；大型音频语料与模型通常通过制品库或数据版本工具管理，并在仓库保存不可变版本 ID、校验和和获取说明。

## 实验追踪

每个模型制品关联代码提交、数据集清单、训练参数、特征/词典版本、依赖、随机种子和评估报告。禁止以同一文件名静默覆盖模型；使用版本标签和校验和确认实际运行的制品。

## 协作实践

通过小型提交、代码评审、分支保护和变更记录管理接口与配置。数据或词典变更需附影响范围和固定集结果。密钥、个人音频和未脱敏录音不得提交到普通源码仓库。

## 练习与验收

完成一次模型配置变更并关联评估结果，再从干净克隆恢复相同模型/数据版本。证明仓库不会意外包含大型或敏感录音。
