# NLU 意图与槽位

自然语言理解（NLU）将文本或语音 token 转换为结构化语义，常见输出包括意图、实体/槽位、规范化值、置信度和拒识状态。语义结果应直接匹配业务 schema，而不是依赖后端解析自由文本。

## 意图分类

意图表示用户希望完成的任务。定义互斥/层级关系、未知意图、澄清和拒识类别；说明多意图表达如何处理。评估除总体准确率外，查看每类 precision/recall、混淆矩阵和置信度阈值行为。

## 槽位抽取与归一化

槽位是执行任务所需参数，如温度、音区、媒体名或目的地。每个槽位定义类型、单位、允许范围、别名、缺省值、非法值、歧义处理和规范化。例如“高两度”需要方向与当前状态，不能仅转换成字符串。

抽取可基于序列标注、实体识别或端到端结构化输出。无论模型结构如何，输出都需经过 schema/type/range 校验；结构合法不代表语义正确。

## 置信度和拒识

分类概率和槽位置信度需校准后再用于策略。低置信度时可澄清、拒绝或请求重复，不应默认执行。阈值需要按意图和风险调整，并在代表性数据上比较误执行与无法完成的代价。

## 训练和错误分析

标注规范应处理多意图、否定、改口、指代、口语省略和冲突槽位。用成对样本仅改变一个词或槽值，验证模型是否响应正确。分层检查领域词、数字、单位、口音转写错误和意图混淆。

## 练习与完成标准

为一个低风险功能定义 schema、意图集和槽位规则；训练或调用基线模型后输出结构化结果与校验错误。构造缺槽、非法值、否定、同义表达和歧义样本，报告每类错误并说明何时澄清/拒识。
