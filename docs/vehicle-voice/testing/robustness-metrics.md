# 语音鲁棒性与稳定性指标

## 鲁棒性

按预定义噪声、距离、说话人和设备条件测量唤醒、识别、语义和业务结果的变化。比较时使用配对样本，并报告场景分层、基线版本和置信区间或重复测量波动。

## 稳定性

长期运行关注崩溃/重启、音频丢帧、队列积压、资源增长、服务恢复时间和成功请求比例。定义运行时长、循环次数、设备/温度条件与故障注入方式。

## 失败分类

区分功能错误、算法退化、环境/设备失败、数据无效和评估器故障。未能执行的测试不能算通过；未知结果应单独报告并附证据。

## 练习与验收

对固定语料运行多轮并模拟断流、重启和网络超时。输出稳定性时间线、恢复时长、资源曲线和分类后的失败清单。
