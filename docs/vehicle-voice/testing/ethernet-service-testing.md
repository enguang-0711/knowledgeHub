# 车载以太网与服务接口测试

## 服务契约

对 SOME/IP 或平台服务接口，记录服务/方法/事件标识、schema 版本、序列化、超时、QoS、发现机制和错误码。接口定义以项目正式契约为准；测试数据不应从猜测的 ID 或私有实现推导。

## 测试维度

检查服务发现、连接建立、请求响应、事件订阅、周期性状态、版本兼容、超时、断连重连和负载/并发。关联请求 ID、网络时间和业务状态回读，区分网络成功与功能动作完成。

## 网络故障

在隔离网络/仿真环境注入丢包、延迟、重复消息、乱序和服务重启。检查有限重试、幂等性、陈旧状态清理和降级提示，避免测试流量进入未授权车载网络。

## 练习与验收

用 mock 服务完成查询请求和状态事件订阅，再注入超时与重连。输出接口版本、报文/事件摘要和恢复证据。
