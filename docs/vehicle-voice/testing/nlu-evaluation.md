# NLU 意图与槽位评测

## 冻结评测契约

测试集应包含文本、目标意图、槽位 span、归一值、上下文和预期动作。标签 schema、同义表达归属、未知类和部分正确的计分规则要预先固定。ASR 输出文本作为输入时，还应区分使用金标准文本与真实识别文本的两套评测。

## 指标

报告意图 accuracy、macro-F1、关键类别 recall、拒识表现；槽位报告 span/F1、完全匹配率和归一值准确率。类别不均衡时不能只看 accuracy。风险较高的意图应单独设门槛并审查误触发。

## 错误归因

将样本链路对齐到 ASR 假设、NLU 输出、对话策略和业务结果，判断错误来自听错、语义混淆、槽位抽取、实体归一、上下文或接口。保存置信度与阈值版本，分析拒识/澄清是否合理。

## 练习与验收

构造同义表达、否定、纠错、缺槽、越界、未知请求和对话上下文样本。输出混淆矩阵、逐样本差异和业务风险分层，而不是单一总准确率。

## 双层评估与错例回放

先用金标准文本测 NLU 本身，再用 ASR 实际输出测端到端影响；两组使用同一意图/槽位 schema 和冻结评测集。分别核算意图 macro-F1/关键类 recall、槽位 span 与归一值准确率、完全匹配率、拒识和澄清结果。

逐样本将 ASR、NLU、对话策略和业务回读并列，区分词识别错误、标签重叠、实体归一、上下文丢失和执行失败。**验收产物**含数据分层、类别支持数、阈值版本、风险错例和拒识案例；高风险意图单设门槛与误触发审查。
