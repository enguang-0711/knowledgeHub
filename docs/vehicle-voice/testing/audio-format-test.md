# 语音数字音频格式测试

## 格式契约

音频接口至少明确编码、采样率、位深/数据类型、端序、声道数、交错方式、帧长、时间戳和通道映射。WAV 文件头字段正确不代表 PCM 内容或采集设备格式必然正确。

## 校验项目

检查文件可解码、样本数与时长一致、幅度范围合理、没有意外静音/削波、声道顺序正确。重采样后验证时长、主频和幅度；不能只修改采样率元数据。

## 边界输入

覆盖空文件、单采样点、非整数帧长、未知编码、通道数不符、截断文件和异常峰值。明确无效输入如何报错，避免静默补零或错误解释。

## 练习与验收

实现一条 PCM/WAV 校验器，为每个文件输出机器可读报告。用生成的正弦波和故意损坏的文件检查采样率、时长、削波与错误分类。
