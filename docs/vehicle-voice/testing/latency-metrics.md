# 语音时延与实时性指标

## 事件定义

先统一起点和终点：音频首帧采集、唤醒确认、首个 partial、final 结果、业务状态确认、首个 TTS 音频播放和播报结束是不同事件。每段时延以同一时钟或校准后的时钟差计算。

## 统计方法

报告样本数、p50、p90/p95、p99、最大值和超时率，并按场景与设备分层。平均值容易掩盖长尾。测量前要区分冷启动、缓存预热、网络条件和持续运行状态。

## 诊断分解

把端到端时间拆到采集缓冲、前端、上行/推理、语义、业务调用与播放。监测队列等待、模型加载和重试时间，避免只在 API 请求处打一个粗粒度时间戳。

## 练习与验收

对固定语料运行多轮，构造网络慢、CPU 负载和长句场景。提交分段时间线与长尾样本，不删除超时/失败数据，并说明异常值处理规则。
