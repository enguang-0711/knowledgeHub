# 车载语音指标导航

各类指标采用不同分母和统计单位，应独立定义后再汇总：

- [WER 与 CER](./wer-cer-metrics)：转写编辑错误和文本归一口径。
- [唤醒与误唤醒评估](./wake-word-metrics)：触发召回、误触发频率和检测延迟。
- [语音时延与实时性指标](./latency-metrics)：阶段时间戳、分位数和长尾。
- [语音鲁棒性与稳定性指标](./robustness-metrics)：场景退化、长时运行和故障恢复。
- [NLU 意图与槽位评测](./nlu-evaluation)：分类、抽取和业务风险指标。

所有报告记录样本/暴露时长、版本、分层和统计口径。
