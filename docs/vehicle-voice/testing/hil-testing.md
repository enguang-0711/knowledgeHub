# 车载语音 HIL 测试

## 适用范围

硬件在环（HIL）把真实 ECU/车机接入受控的信号仿真环境，可验证驱动、通信、时序和部分真实硬件行为。它不能自动覆盖真实道路安全或所有座舱声学条件；需明确台架的模型精度和未覆盖范围。

## 台架管理

记录 ECU、固件、线束、仿真器、音频接口、信号模型、标定和工具版本。用例前确认台架空闲、状态已复位、故障注入设置正确；用例后恢复默认状态并释放独占资源。

## 执行和恢复

设计连接丢失、信号超时、音频设备异常、ECU 重启和异常退出场景。脚本需等待可观测状态而非固定长 sleep，并对状态恢复失败进行隔离和告警。共享台架的并发执行要通过资源锁控制。

## 练习与验收

在仿真 HIL 或教学台架执行低风险查询用例，制造一个通信中断并验证恢复。报告包含台架身份、信号配置、时间戳、原始证据和环境失败分类。

## 台架测试运行卡

执行前记录 ECU/固件、线束、仿真模型、音频设备、信号配置、软件/模型版本和台架校准；确认资源独占、初始状态、停止条件与紧急中断可用。按固定测试脚本先跑基线，再注入设备断开、网络超时或 ECU 重启。

**验收产物：**输入音频与信号时间线、trace/log、故障触发点、恢复状态和测试后环境清理记录。自动化应等待状态事件并设超时；台架未复位、设备异常或状态回读缺失应作为环境失败单独处理。
