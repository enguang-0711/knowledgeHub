# 唤醒与误唤醒评估

## 指标定义

报告真实关键词触发率/漏唤醒率，以及负样本上的误唤醒频率。误唤醒应按每小时或规定暴露时长统计，同时写明音频时长、负样本类别和判定窗口。只报告“准确率”会被大量静音样本主导。

## 阈值与时延

阈值变化会形成召回与误触发权衡。报告不同阈值下曲线、触发延迟、重复触发和冷却策略；冻结唤醒模型、前端、阈值及音频采集链路。

## 分层

按口音、距离、音量、噪声、播放媒体、多人说话和关键词变体报告。正样本说话人与负样本录音需按会话隔离，避免同源重复录音造成偏差。

## 练习与验收

构造包含关键词、相似词、背景电视/音乐和静音的长时测试集。报告小时误触发数、真实触发召回、检测延迟和每个失败样本。

## 长时负样本评测

正样本按说话人/口音/距离/音量切片，负样本记录有效暴露小时及来源，包含近似词、日常对话、导航/媒体播报、电视、音乐、多人交谈和静音。固定前端、模型、阈值、冷却逻辑及判定窗口，避免版本不一致造成不可比。

**验收产物：**各阈值的召回-误唤醒曲线、每小时误触发、触发延迟、重复触发和失败片段索引。定义置信区间/重复运行策略；样本暴露太短而观察不到误触发时，应说明统计上限，不能报告为零风险。
