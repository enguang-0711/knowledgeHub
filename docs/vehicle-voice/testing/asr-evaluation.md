# ASR 识别评测

## 评测对象与输入

ASR 评测要冻结模型、解码器、热词、音频前端、采样格式、端点策略和参考转写规范。文件离线评测适合快速比较识别器；麦克风注入或座舱播放才覆盖相应的驱动、路由、声学和实时链路，报告需标清覆盖范围。

## 指标与错误分类

常用 WER/CER 衡量替换、删除和插入错误。除总体分数外，应按噪声、距离、说话人、口音、句长、实体类型和命令类型分层，保存逐样本假设。错误还要区分前端丢失、端点截断、专名错识和文本归一口径差异。

## 流式结果

检查 partial 更新、稳定性、final 一致性、首个结果延迟、端点延迟、取消和超长输入。partial 允许被修订；断言需依据产品协议判断稳定窗口和最终提交，不能简单要求每个中间文本与最终结果完全相同。

## 练习与验收

建立固定音频集和参考文本，运行两个模型版本，输出总体/分层指标、样本差异、版本元数据和失败音频索引。确认归一化规则变更会触发基线重算。
