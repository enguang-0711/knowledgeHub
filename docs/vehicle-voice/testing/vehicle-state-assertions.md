# 车辆与业务状态断言

## 状态证据

判断语音功能完成，应读取可信的应用状态、车机服务响应、仿真信号或获批台架上的车辆回读。区分命令被解析、请求被接受、信号已发送和目标状态已确认。

## 断言契约

为状态定义单位、精度、更新时间、有效值、前置条件和等待超时。异步状态要采用有界等待与稳定窗口，不以固定延时假设执行完成。查询类功能需确认返回值与当前状态一致。

## 安全和幂等

使用 mock/仿真或隔离台架进行自动化。控制类操作应确认权限、车辆状态、停止条件和硬件联锁；重复执行用例时验证幂等性和状态复位。

## 练习与验收

用虚拟服务验证“请求—状态变化—反馈”闭环，故意让服务接受请求但不更新状态，确保测试判失败并保留独立回读证据。
