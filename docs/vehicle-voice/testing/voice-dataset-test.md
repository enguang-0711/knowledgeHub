# 语音测试数据集管理

## 数据记录

每条语音样本应使用稳定 ID 关联原始音频哈希、转写、说话人/会话去标识符、采集设备、声学条件、采样格式、标签版本、授权状态和预期用途。敏感录音按最小权限存储并设置保留期限。

## 语料分层与切分

根据唤醒、ASR、NLU 或端到端目标定义样本单位和标签。按说话人、会话、车辆或采集批次隔离训练、调参和冻结评估集，防止同一录音的变体跨集合泄漏。保留困难样本和边界样本的来源。

## 自动质量门禁

检查文件可解码、采样率/声道符合要求、时长合理、没有意外静音/削波，转写与标签字段有效，哈希去重且切分无冲突。格式转换工具和参数也必须版本化。

## 练习与验收

设计 manifest、格式检查器和授权字段检查，故意注入缺失文件、错误采样率和跨切分重复样本。门禁应拒绝问题并给出可定位原因。

## 数据集门禁设计

定义 manifest schema，导入时校验文件哈希、格式/采样率/声道、样本时长、静音/削波、转写状态、标签版本、会话去标识符和授权用途。按说话人、会话、车辆或采集批次切分；合成、增强和裁剪派生样本必须继承源样本分组。

**验收产物：**数据卡、切分泄漏/近重复报告、文件质量摘要、异常样本隔离清单及可重建命令。门禁故障要具体指出样本 ID 和错误字段；删除或修订敏感样本时追踪其派生制品和评测报告影响。
