# TTS 语音注入测试

## 适用范围

TTS 可快速生成可重复的测试语音，适合覆盖文本变体、参数和回归；合成声音与真人在韵律、音色、口音和噪声特征上存在差别。TTS 通过的结果不能替代真人语音或真实座舱声学测试。

## 资产生成

保存输入文本、TTS 引擎/音色/版本、发音词典、语速/音量/韵律参数、生成时间、音频格式、随机种子（如适用）和文件哈希。固定已生成文件可避免引擎升级引入不可控差异。

## 注入路径

将合成语音分别用于识别器文件接口、数字音频注入或扬声器播放。每条结果标注实际经过的音频前端、设备和声学路径。播放时校准电平、位置并同步采集，防止削波和首尾截断。

## 练习与验收

为专名、数字、同义命令和易混发音生成固定语料，执行版本回归。对代表性样本再使用真人录音核验差异，报告合成语音的适用边界。
