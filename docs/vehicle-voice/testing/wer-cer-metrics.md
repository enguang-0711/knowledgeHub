# WER 与 CER 评估指标

## 定义

WER（词错误率）和 CER（字符错误率）以编辑距离计量替换、删除和插入错误：`错误率 = (S + D + I) / N`，其中 `N` 是参考文本单位数。中文通常报告 CER；中英混合场景需明确分词/字符规则。错误率可能大于 100%。

## 归一化

比较前要规定大小写、标点、空格、数字、单位、英文缩写和口语词的归一规则。参考文本与假设文本必须经过同一规范化管线，并保留原文；规则变更会改变历史分数，应记录版本并重算基线。

## 解释边界

整体 WER/CER 不反映命令语义风险：一个关键槽位错字可能导致错误动作，多个无关口头词也可能使分数变高。应同时看专名、数字、关键实体、场景分层和业务成功率。

## 练习与验收

手算含替换/删除/插入的样例，再用固定工具计算。输出汇总指标、逐样本错误和归一规则版本，并验证空参考、空假设和重复文本的处理方式。

## 计分实现与手工复核

冻结文本归一脚本、分词/字符单位和空参考策略。用少量手工样例分别验证替换、删除、插入、空假设、空参考和中英混合文本，再与正式计分工具交叉检查；保留原始文本和规范化结果。

**验收产物：**S/D/I/N 汇总、总体及分层 WER/CER、逐样本对齐、归一规则版本和关键实体错误清单。报告解释分数变化来自真实模型输出还是规则改动；业务风险较高的数字/车辆实体需单独计分。
