# 车载语音音频注入测试

## 注入层级

文件直喂识别器只验证算法接口；数字 PCM 注入覆盖部分软件前端；音频设备回环覆盖设备路由；扬声器在座舱播放并由麦克风采集，才会覆盖声学传播、麦克风与座舱噪声。每种方法都应写明绕过了哪些部件。

## 资产校验

运行前检查采样率、位深、声道、时长、峰值、静音、削波和编码。格式转换要保留原文件并记录工具与参数；重采样不能仅改文件头。每个样本使用稳定 ID 和哈希关联预期转写、录制条件与授权。

## 执行控制

定义播放音量、麦克风增益、扬声器/麦克风位置、环境噪声、车辆状态和录音时长。播放与采集要有同步触发或时间戳，防止首尾截断。失败样本需要保留输入、注入配置、设备版本和原始输出。

## 练习与验收

同一批语音分别走文件直喂和座舱播放路径，比较差异并说明差异来源。重复运行时记录实际播放电平、环境和设备身份，证明结果可以重现。
