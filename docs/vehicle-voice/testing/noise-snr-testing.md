# 噪声与信噪比测试

## SNR 口径

信噪比通常按语音有效段和噪声段的功率比计算：`SNR_dB = 10 log10(Pspeech / Pnoise)`。实际车内声场中，语音与噪声时变且相关，必须说明分段方法、加权方式、测量位置和校准条件；报告一个 SNR 数值不能完整描述噪声场景。

## 场景构造

区分稳态空调、路噪、风噪、音乐、喇叭、多人交谈等噪声。数字混音可精确控制相对电平，但不包含空间传播与麦克风效应；真实声学测试更接近产品使用，却更难完全复现。两类结果应分开报告。

## 分析

按 SNR 档位查看唤醒、VAD、ASR 和业务成功率，以及语音失真、漏唤醒、误唤醒和响应时间。保留输入/输出音频和算法版本，检查降噪或 AGC 是否把噪声误判为语音。

## 练习与验收

从干净语音生成多个数字混音 SNR 档位，再挑选代表性场景做声学播放。说明两种结果的可比范围及差异，固定随机种子与噪声文件版本。
