# 语义与实例分割

分割为图像像素或目标实例分配类别。语义分割标注每个像素所属类别；实例分割还要区分同类的不同对象。像素级任务对边界、标签分辨率和类别比例很敏感。

## 标签和输出

定义类别 ID、背景、忽略像素、边界规则、遮挡和不可见区域。训练时图像与 mask 必须经过相同几何变换；mask 通常采用最近邻插值，避免线性插值产生不存在的类别编号。输出可能是每像素 logits、类别图或实例 mask，需说明后处理与映射。

## 评估方法

IoU 对每类统计交并比，mIoU 再按指定规则对类别平均。类别频率差异大时，像素准确率可能被大面积背景主导。可补充边界质量、目标级召回和关键区域指标，但需明确这些指标的计算定义。

检查掩码是否出现空洞、锯齿、边界偏移和小目标消失；按类别、距离、遮挡和图像区域分析错误。标注边界本身有主观性时，应先统一规范再比较细小像素差异。

## 部署注意事项

高分辨率分割输出占用较大显存和带宽。需要评估输出降采样、类别压缩、ROI 推理和后处理的精度/延迟取舍。量化或插值变化可能让边界退化，应在目标硬件输出上复核。

## 练习与完成标准

检查一组图像-mask 对的尺寸、类别值和空区域；训练或运行一个分割基线，计算每类 IoU 并保存边界可视化。人为改变一次 mask 插值方式，说明标签值和指标怎样受影响。
