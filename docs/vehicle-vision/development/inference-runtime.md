# 视觉推理运行时

## 推理生命周期

运行时负责设备发现、模型加载、输入缓冲、预处理/推理/后处理调用、同步/异步执行、内存回收和错误上报。明确上下文创建成本、线程安全、输入输出内存位置和异步完成通知。

## 集成要点

验证模型输入 shape、layout、数据类型、stride 和归一化；输出需映射回原图/车辆坐标并应用一致的阈值与类别表。多路相机并发时检查执行队列、上下文复用、内存峰值和互相干扰。

## 故障与兼容

处理模型文件损坏、算子不支持、设备不可用、推理超时、内存不足和加速器重置。运行时与模型格式、驱动和硬件版本需要兼容矩阵。不能只因模型成功加载就判定输出正确。

## 练习与验收

构建单帧与多帧推理适配器，记录输入帧 ID、加载耗时、推理耗时和错误码。注入模型损坏及设备不可用，验证恢复或安全失败路径。

## 推理服务生命周期

把设备发现、模型解析/编译、上下文创建和每帧执行分成阶段计时；昂贵的一次性初始化不应误算进稳态帧延迟，也不能在每帧重复创建上下文。接口明确输入/输出 buffer 所有权、对齐、layout、异步完成事件及调用线程限制。

为多路相机设定并发上限和队列策略，避免共享上下文的线程安全假设未经验证。设备重置、内存不足、模型不兼容和超时要映射到结构化错误状态；失败帧不能沿用上一帧结果而不标记数据年龄。

**验收产物：**在单帧、多帧和多流负载下报告初始化/执行/排队时间、峰值内存及恢复行为；用损坏模型、错误 shape 和设备不可用注入验证服务明确失败并可重新初始化。
