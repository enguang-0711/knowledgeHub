# 视觉图像预处理

## 预处理契约

预处理将传感器图像变成模型张量，需冻结裁剪、缩放、letterbox、颜色转换、数值归一化、通道顺序、插值和 padding 值。训练和推理必须采用相同变换，且将几何变换记录下来供输出反投影。

## 几何与数值影响

缩放/裁剪会改变目标尺寸和像素坐标；插值方式影响细小边缘；归一化范围错误会导致模型分数整体异常。图像增强适合训练分布扩展，但验证/线上输入不可随机增强。

## 实现与效率

核对预处理运行在 CPU、ISP、GPU 或 NPU 的位置，测量颜色转换和内存复制成本。使用异步 pipeline 时关联帧 ID，避免前处理结果和原始时间戳错配。

## 练习与验收

对同一图像生成训练参考张量和端侧张量，检查 shape、均值/标准差、像素采样值和反映射框位置。人为改变 RGB/BGR 或 padding 值，验证回归能发现差异。
