# 视觉模型导出

## 导出目的

模型导出把训练框架中的权重与计算图转换为部署运行时可加载的制品。要明确目标格式、算子集合、动态/固定输入形状、布局、数据类型、输出节点和版本兼容性。

## 转换检查

比较原框架与导出图的输入预处理、输出张量和算子精度。对代表性边界样本进行逐层或输出级数值检查；关注动态 shape、padding、Resize、归一化和后处理是否被纳入图。

## 交付制品

模型文件应与类别表、预处理、阈值、标签映射、配置、工具链版本和校验和一起发布。保留原模型和转换日志；转换失败或算子替换要明确记录，避免模型文件与业务配置错配。

## 练习与验收

从一个开源模型导出到目标格式，比较固定样本上的张量差异、任务指标和文件大小。使用干净环境从制品清单加载并运行推理。

## 导出、比较与制品冻结

导出前先固定 checkpoint、输入输出节点、动态维度、opset/工具链和前后处理边界；导出后检查图结构、算子覆盖和目标运行时编译日志。用同一批金样本逐层比较原框架与目标运行时张量，检测 NaN、shape 错误、量化/浮点偏差和阈值附近的决策变化。

检测任务要检查框反变换、类别索引、分数和 NMS；分割任务要检查 mask 尺寸、类别映射和上采样。记录被替换或融合的算子及转换警告，不把“模型文件能加载”当成一致性证明。

**验收产物：**发布不可变模型文件、SHA-256、转换命令、工具版本、输入契约和配套配置；报告数值误差、任务指标差异、文件大小及未支持算子，保证清洁环境可以复现推理。
