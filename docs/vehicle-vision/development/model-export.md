# 视觉模型导出

## 导出目的

模型导出把训练框架中的权重与计算图转换为部署运行时可加载的制品。要明确目标格式、算子集合、动态/固定输入形状、布局、数据类型、输出节点和版本兼容性。

## 转换检查

比较原框架与导出图的输入预处理、输出张量和算子精度。对代表性边界样本进行逐层或输出级数值检查；关注动态 shape、padding、Resize、归一化和后处理是否被纳入图。

## 交付制品

模型文件应与类别表、预处理、阈值、标签映射、配置、工具链版本和校验和一起发布。保留原模型和转换日志；转换失败或算子替换要明确记录，避免模型文件与业务配置错配。

## 练习与验收

从一个开源模型导出到目标格式，比较固定样本上的张量差异、任务指标和文件大小。使用干净环境从制品清单加载并运行推理。
