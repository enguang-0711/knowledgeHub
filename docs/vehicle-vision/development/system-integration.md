# 视觉系统集成

算法集成需要统一接口、时间、坐标、内存所有权和故障语义。一个模型在本地程序中能运行，并不意味着它已成为可靠的车端组件。

## 定义接口

输入应描述图像格式、尺寸、相机 ID、采集时间、标定/车辆状态版本和有效性。输出应描述对象/状态、坐标系、单位、置信度、采集时间、输出时间、数据年龄和错误状态。字段单位和空值行为要有明确约定。

## 线程和队列

划分采集、预处理、推理和输出线程时，明确缓冲区所有权、队列容量、背压策略和停止顺序。并行推理可能导致输出乱序；应按时间戳或序号处理。实时功能通常要限制数据年龄，不能为处理完所有历史帧而长期滞后。

## 生命周期与错误处理

定义服务启动、模型加载、相机接入、运行、断流、恢复和关闭状态。超时、设备不可用、输入格式错误、内存不足和模型错误需映射到稳定错误码。失败路径不得返回未标记的旧输出。

接口兼容变更应做版本管理，并确认下游消费者的升级和回退策略。车辆信号或外部传感器加入后，保证其时间戳和坐标变换与图像匹配。

## 练习与完成标准

把一个推理程序封装成可启动/停止的服务；测试正常输入、格式错误、超时和断流恢复。每条输出可关联输入帧及版本；并发运行时不乱序、不无限积压，停止后释放资源。
