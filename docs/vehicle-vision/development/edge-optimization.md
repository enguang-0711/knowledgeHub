# 端侧优化与量化

端侧优化应先测量瓶颈，再选择量化、算子融合、内存复用或并行方案。优化目标不只是模型核的耗时，还包括精度、端到端时延、内存、功耗、温度和稳定性。

## 精度与量化

FP32、FP16、INT8 等精度模式在速度、内存和数值误差间取舍。INT8 通常需要代表性的校准样本或量化感知训练；校准数据需覆盖目标类别、距离、光照和相机条件。观察每层或关键输出误差，检查误差是否集中在小目标、低置信度边界或稀有类别。

量化后用相同样本比较模型指标和任务切片；只看平均精度可能掩盖安全关键类别退化。任何阈值重新调整都应记录并重新评估。

## 计算和数据搬运

- 减少不必要的 CPU/GPU 拷贝，明确缓冲区是否可共享及其生命周期。
- 使用内存复用、合理的输入尺寸和平台支持的算子融合。
- 使用异步流水线时控制队列和同步，关注结果乱序与数据年龄。
- 依据 profiler 调整线程、并发和 batch；实时 batch=1 场景不能直接照搬离线批处理参数。

## 优化决策

每次只改变可解释的一组因素，保存前后版本和运行条件。比较端到端收益与额外复杂度；若优化只减少模型推理时间，却增加排队或数据转换，就不一定改善用户可见时延。

## 练习与完成标准

对一个部署模型建立 FP32/FP16 或 INT8 对比，记录目标硬件、软件版本、校准集、精度分层、p50/p95 延迟、内存和温度。分析一项精度退化，决定接受、回退还是调整方案，并给出依据。
