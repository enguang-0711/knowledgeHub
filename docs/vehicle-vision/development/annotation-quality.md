# 视觉标注质量

## 标注协议

标注规范需定义类别边界、遮挡/截断、忽略区、困难样本、多边形/框边界、车道线拓扑、跟踪 ID 生命周期和坐标像素约定。示例应覆盖边界案例，并说明标注工具导出格式。

## 质量控制

使用抽样复核、双人标注、一致性统计和仲裁流程；关注类别混淆、框松紧、漏标、实例 ID 交换、分割边缘和属性偏差。自动规则可检测越界框、空多边形和不可能的帧间 ID，但不能替代语义审查。

## 版本与追溯

标签与原始帧、规范版本、标注员、工具版本和修改历史关联。规范变化时要判断是否需要重标或转换，并防止同一数据版本混用两套口径。

## 练习与验收

为行人和车辆定义标注规范，双人标注一小段视频，统计差异并仲裁。交付机器可校验的标签文件、差异清单和最终版本记录。

## 标注落地流程

1. 先把任务拆成可观察标签：类别、几何边界、可见性、遮挡、实例关联和“不确定/忽略”状态分别定义，给每种边界情况配正反例。
2. 用小批量试标验证规范，统计类别混淆、框/掩码偏差和视频 ID 断裂；将分歧按“规范不清、工具限制、操作错误、源图不可判”分类，先修规范再扩大标注。
3. 发布前冻结 schema 与工具版本，自动校验坐标范围、类别枚举、帧引用和 ID 生命周期；人工抽检仍需覆盖稀有类及长尾样本。

**交付验收：**提交标注规范、抽样方案、分歧仲裁记录、机器校验报告和标签版本差异。规范变更时说明旧标签是否重标、映射或从训练集排除，并确保指标能回溯到当时使用的标签口径。
