# 图像分类

图像分类把输入图像映射到一个或多个类别，常作为交通标志/灯状态、乘员状态等任务的一部分。必须先定义类别和判定规则，再选择模型和阈值。

## 问题定义

明确是单标签还是多标签、类别互斥关系、是否有“未知/拒识”类别，以及一个样本如何构成。若模型只分类裁剪区域，裁剪框来自何处、越界如何处理、裁剪中没有目标时如何标记都要写清。

## 输出和阈值

Softmax 或 sigmoid 输出表示模型相对分数，不自动保证校准良好。选择阈值要考虑类别不平衡、漏报/误报代价和下游策略；阈值绑定模型版本与评估数据。若场景不属于训练类别，应定义拒识或低置信度行为。

## 评估和错误分析

查看混淆矩阵、每类 precision/recall、宏/微平均和置信度分布。类别不平衡时总体 accuracy 可能掩盖稀有类表现。按光照、遮挡、相机和目标尺度分层，检查“相邻类别混淆”“目标不存在”“标签定义含糊”等错误来源。

## 练习与完成标准

训练一个小型分类器，保存每样本 logits/预测/标签；比较两个阈值和一次类别不平衡处理方案。输出混淆矩阵、每类召回、拒识样本及错误图像，并解释阈值改变造成的 FP/FN 变化。

## 数据准备与模型调试

先明确样本单位是整图还是目标裁剪，并保证裁剪来源在训练和部署一致。训练集按行程/车辆/相机配置分组切分；对长尾类别可采用重采样或损失权重，但验证集应保持接近目标真实分布。检查增强后图像是否仍保留类别语义。

输出层需区分单标签 softmax 与多标签 sigmoid；概率阈值应基于验证集校准并绑定模型版本。对低置信度、未知目标和输入无效分别定义拒识行为，避免把最大分数机械地当作可靠类别。

**验收产物：**保存每样本 logits/预测、类别表和阈值版本；报告混淆矩阵、每类支持数/召回、置信度校准和光照/遮挡/尺寸切片。分析类别边界错例，并说明阈值调整如何改变 FP/FN 与下游动作。
