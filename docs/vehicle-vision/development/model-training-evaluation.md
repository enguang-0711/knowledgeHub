# 视觉模型训练与评估

## 可复现训练

训练记录包括数据快照、代码提交、依赖、随机种子、预处理、模型结构、优化器、超参数、检查点和硬件。验证集用于选择方案，测试集应保持隔离，避免反复调参造成隐式泄漏。

## 训练诊断

跟踪训练/验证损失、任务指标、学习率和吞吐。训练性能好而验证性能差通常提示过拟合、标签噪声或分布偏移；训练和验证同时差可能是标签/预处理/优化设置问题。按目标大小、天气、光照、相机和场景切片定位错误。

## 评估报告

报告指标定义、匹配阈值、类别映射、NMS、置信度门限、样本数量、数据版本和代码/模型版本。提供代表性误检、漏检、定位误差、时序抖动与资源表现，避免只贴一个 mAP 或 IoU。

## 练习与验收

运行一个基线并做一次有假设的改动，比较固定验证集和保护集。确保每个结果可从训练记录重现，且错误分析能回链到源图像/视频帧。

## 设计一轮可解释的实验

开始前写出假设，例如“提高输入分辨率能改善远距离小目标召回”，并只改变一项主要因素。固定训练/验证/保护测试划分、随机种子、增强、优化器、检查点选择规则和评估脚本；记录每次运行的代码、数据与配置版本。

训练时按 epoch 跟踪损失、学习率、任务指标、吞吐和资源；结束后用验证集选模型，再只对冻结测试集做最终比较。逐样本分析漏检、误检、定位偏差、类别混淆及标签问题，并按目标大小、距离、昼夜和相机切片。

**验收产物：**提交可复跑配置、训练曲线、总体与分层指标、样本级错误清单和改动前后对照。报告分母、忽略规则与阈值；若多个因素同时改变，结论应标记为无法单独归因。
