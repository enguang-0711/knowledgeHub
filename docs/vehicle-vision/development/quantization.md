# 视觉模型量化

## 基本概念

量化用低精度表示权重和/或激活，以减少模型存储、带宽或计算成本。常见路线有训练后量化（PTQ）和量化感知训练（QAT）；对称/非对称、逐张量/逐通道策略会影响精度和硬件效率。

## 校准数据

PTQ 校准集要代表真实输入分布，包括曝光、天气、目标尺寸和相机差异。校准清单、预处理、量化参数和工具版本必须固定。代表性不足时，少数激活异常值可能显著损害小目标或边界精度。

## 联合评估

同时比较浮点/量化模型的任务指标、关键场景切片、延迟、内存、功耗和模型大小。检查算子回退到 CPU、精度混合和数据搬运，不能只凭理论位宽推断收益。

## 练习与验收

对检测模型执行 PTQ，选取代表性校准集并检查不同目标尺寸上的变化。设定业务可接受的精度回退与资源收益门槛，超出门槛则保留浮点或尝试 QAT。
