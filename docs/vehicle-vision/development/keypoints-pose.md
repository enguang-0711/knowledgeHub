# 关键点与姿态估计

关键点模型输出人体、面部或物体上的指定点；姿态估计进一步根据这些点估计方向或关节结构。任务定义取决于关键点 schema、可见性和参考坐标系。

## 定义和标注

为每个关键点定义名称、顺序、解剖/物理位置、可见性标签和不可标注条件。不同数据集的点位顺序、左右方向和可见性编码可能不同，训练前需显式映射。遮挡点的坐标是否仍需标注，要遵循统一规范。

模型可采用热力图、坐标回归或其他输出形式。热力图解码时要明确峰值、亚像素偏移、坐标缩放和低置信度处理。姿态角度还需要定义零位、轴顺序、单位和参考坐标。

## 评估和时序

按关键点计算像素误差、归一化误差或项目定义的关键点准确率，并按可见/遮挡状态分层。面部或人体尺度变化时，归一化分母需固定定义。视频场景还应观察关键点跳变、短时丢失和状态估计延迟。

## 常见问题

- 关键点顺序在数据、模型和业务接口间不一致。
- 将不可见点当成背景或错误位置参与损失。
- 角度坐标系和度/弧度混用。
- 单帧输出看似准确，连续帧因噪声出现明显抖动。

## 练习与完成标准

建立一个小型关键点样例集，验证标签顺序、越界和可见性；可视化预测与标签，并计算按点位/可见性分层的误差。对一段视频画出单点坐标曲线，区分模型噪声和真实快速动作。
