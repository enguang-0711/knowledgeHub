# 语义分割

## 任务定义

语义分割为每个像素分配类别，例如道路、车辆、行人或天空。同类不同实例共享标签，因此它适用于区域理解，不直接提供单个对象的身份。

## 标签与训练

类别 ID、忽略区、边界像素、遮挡和无效图像需定义一致。训练时关注类别不平衡、边界细节、分辨率和数据增强；缩放标签必须使用最近邻插值，避免生成不存在的类别 ID。

## 评估和部署

常见指标包括每类 IoU、mean IoU、像素准确率和边界质量。总体指标容易被大面积背景主导，应报告小目标、关键区域和昼夜/天气切片。部署需核对输出 stride、上采样、色彩映射和类别表版本。

## 练习与验收

训练或运行一个小型语义分割基线，输出彩色叠加图、混淆矩阵和类别 IoU。人为错配类别表，观察为何只看图像颜色可能掩盖 ID 契约问题。

## 从标签到像素输出的实现核对

冻结类别 ID、背景/忽略值、边界像素归属和多边形栅格化规则；图像缩放时同步变换标签，掩码通常使用最近邻，避免插值生成不存在的类别。训练损失中的 class weight、ignore index 和采样策略要与评估口径一致。

推理后处理检查输出 logits/probability、通道到类别映射、上采样尺寸、裁剪偏移和色彩调色板。用细车道线、小目标、相邻类别边界和部分遮挡检查边缘是否被下采样吞掉。

**验收产物：**提供预测/真值叠加图、每类 IoU/Dice、边界容差指标及场景切片，并验证全背景、无效像素和未知类别行为。不要用总体像素准确率替代少数关键类别评估。
