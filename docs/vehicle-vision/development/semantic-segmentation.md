# 语义分割

## 任务定义

语义分割为每个像素分配类别，例如道路、车辆、行人或天空。同类不同实例共享标签，因此它适用于区域理解，不直接提供单个对象的身份。

## 标签与训练

类别 ID、忽略区、边界像素、遮挡和无效图像需定义一致。训练时关注类别不平衡、边界细节、分辨率和数据增强；缩放标签必须使用最近邻插值，避免生成不存在的类别 ID。

## 评估和部署

常见指标包括每类 IoU、mean IoU、像素准确率和边界质量。总体指标容易被大面积背景主导，应报告小目标、关键区域和昼夜/天气切片。部署需核对输出 stride、上采样、色彩映射和类别表版本。

## 练习与验收

训练或运行一个小型语义分割基线，输出彩色叠加图、混淆矩阵和类别 IoU。人为错配类别表，观察为何只看图像颜色可能掩盖 ID 契约问题。
