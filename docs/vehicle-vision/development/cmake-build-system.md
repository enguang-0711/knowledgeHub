# 视觉项目 CMake 构建系统

## 工程组织

将库、应用、测试、模型工具和第三方依赖分层管理。公开头文件与实现分离，目标之间显式声明 include、编译选项和链接依赖，减少全局变量污染。

## 可复现构建

为主机与目标平台区分 toolchain、sysroot、ABI、编译器和构建类型。记录依赖版本和选项；CI 在干净目录执行配置、构建和测试。不要在源码中硬编码开发者本机路径。

## 依赖与制品

明确 OpenCV、推理运行时、驱动接口等依赖的来源和兼容范围。模型、类别表和配置作为版本化运行制品管理，并验证安装包携带正确文件。

## 练习与验收

为一个图像处理库创建可安装 CMake target，支持主机单测和交叉编译配置。干净环境可按 README 构建并运行最小推理示例。
