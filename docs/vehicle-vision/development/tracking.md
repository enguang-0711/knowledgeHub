# 多目标跟踪

多目标跟踪在视频帧间维持目标身份和运动状态。常见跟踪-by-detection 系统先检测目标，再将当前检测与已有轨迹关联；整体效果受检测质量、帧率、时间戳和关联策略共同影响。

## 轨迹生命周期

定义轨迹如何创建、确认、更新、暂时丢失、重新关联和终止。状态可包含位置、速度、类别、置信度、最后观测时间和 ID。状态转移阈值应结合帧率和场景验证；固定帧数的失效窗口在帧率变化时可能代表不同实际时间。

## 数据关联

候选关联可使用 IoU、外观特征、运动预测或其组合。卡尔曼滤波是常见的运动状态估计方法，但模型假设和噪声参数要适合目标运动。遮挡、交叉、相似外观和检测漏帧会导致 ID 切换。

## 评估与诊断

除检测指标外，跟踪需关注 IDF1、HOTA 等轨迹层指标及 ID 切换、轨迹中断、初始化延迟。指标名称必须绑定实现和评估配置。用视频可视化轨迹 ID、观测/预测状态、关联代价和时间戳，便于诊断。

## 常见问题

- 输入帧乱序或时间戳错误，导致运动预测方向不合理。
- 短暂漏检后立刻删除轨迹，造成频繁重建 ID。
- 长时间仅靠预测外推，输出已不再代表当前观测。
- 多线程推理完成顺序变化，跟踪器收到了乱序帧。

## 练习与完成标准

在固定视频上实现或运行一个检测关联跟踪基线，输出轨迹、帧时间和关联状态；构造丢帧、遮挡和交叉场景，分析 ID 切换与轨迹恢复。说明状态重置和过期输出规则。
