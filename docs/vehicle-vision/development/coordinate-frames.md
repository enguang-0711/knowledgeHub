# 视觉坐标系与几何变换

## 常见坐标系

车载视觉可能涉及像素坐标、归一化图像坐标、相机坐标、车辆坐标、世界/地图坐标和鸟瞰图坐标。每个坐标系都应定义原点、轴方向、单位、左/右手性和时间参考。

## 变换链

刚体变换可用齐次矩阵组合旋转和平移。明确变换方向（A 到 B 还是 B 到 A）及矩阵乘法顺序；投影前处理齐次坐标，关注深度为零/负值和有效视野。像素坐标变换还要考虑缩放、裁剪、letterbox 和镜头畸变。

## 误差传播

内外参误差、安装误差和目标深度会影响地面投影与距离估计。远距离和视线掠射区域通常对角度误差更敏感，应按位置分层验证，而非只计算全画面平均误差。

## 练习与验收

实现像素到相机再到车辆坐标的变换和逆变换测试。用合成点验证已知投影；将坐标轴绘制到图像/BEV 上，检查方向和单位是否一致。

## 几何实现的自检方法

约定记号 `T_A_B` 表示把 B 系坐标变换到 A 系，并在接口里固定列向量/行向量、旋转顺序、角度单位和右/左手系。先写出像素到归一化相机、相机到车辆、车辆到世界的变换链，再实现矩阵组合，避免凭变量名猜方向。

使用已知三维点做“投影→反投影”往返测试；平面目标另测地面单应性，深度为零、负深度、视野外和 NaN 要有定义行为。对裁剪、缩放与 letterbox，保存每帧变换参数并把检测框反映射回原始图像。

**验收产物：**坐标系图、单位表、合成点测试和实测控制点残差。分别报告近/远距离与画面位置误差；如果误差随距离增长，应优先检查外参角度与高度，而不是只调整输出平移量。
