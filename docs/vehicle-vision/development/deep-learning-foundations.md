# 深度学习基础与训练机制

本专题覆盖视觉模型训练和推理的共同基础。目标是能读懂一次训练如何从输入张量产生输出、损失和参数更新，并能定位数据、梯度或配置问题。

## 张量和网络

理解 batch/channel/height/width 维度、dtype、设备和内存布局。卷积网络通过局部卷积和多层特征学习图像表征；归一化、激活和残差连接影响训练与特征传播；注意力和 Transformer 用于建模更广范围的特征关系。模块选择应联系任务效果和算力/内存成本。

训练模式与推理模式可能采用不同的归一化和随机操作。导出前需确认模型处于正确模式，输入尺寸和动态形状符合运行时要求。

## 损失、梯度和优化

损失函数把模型输出和标签映射为可优化目标。分类常见交叉熵，回归和定位使用相应距离损失；检测/分割模型通常由多个损失项组成。正负样本分配、类别权重和损失尺度会影响训练重点。

反向传播通过链式法则计算梯度。优化器根据梯度更新参数，学习率计划控制更新步长。监控总损失及各分量、梯度范数、训练/验证指标和样本预测，避免只看一个 loss 值。

## 泛化、增强与复现

过拟合表现为训练结果持续改善而验证表现变差。数据增强、权重衰减、早停或模型容量调整可能缓解，但首先检查切分、标签和数据分布。固定代码、配置、数据版本、随机种子和权重哈希；断点续训时也要记录优化器状态和训练步数。

混合精度能降低计算和存储开销，但可能需要损失缩放或特定算子处理。它的速度与数值效果应在目标硬件上验证。

## 调试训练

1. 用少量样本尝试过拟合，验证模型、标签和损失路径基本正确。
2. 可视化增强后的图像和标签，确认几何变换对齐。
3. 检查输出维度、梯度是否为零/NaN、类别映射和损失分量。
4. 对比训练、验证和分层指标，检查数据泄漏与域差异。
5. 保存 checkpoint 和配置，确认可以从中断位置恢复。

## 练习与完成标准

使用小型分类数据训练基线，记录配置、曲线、验证混淆矩阵和失败样本；做一次故意的标签错位或类别映射错误，并用调试流程定位。随后说明过拟合、梯度异常和数据问题各自可能留下什么证据。
