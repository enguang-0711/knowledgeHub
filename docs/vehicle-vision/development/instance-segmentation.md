# 实例分割

## 任务定义

实例分割既预测对象类别，也为每个对象输出独立掩码，适合需要区分相邻同类目标的场景。输出通常包含类别、置信度、边界框及像素掩码或压缩表示。

## 后处理与接口

模型可能使用候选框后处理或端到端掩码预测。要定义掩码分辨率、坐标映射、阈值、NMS/匹配策略和实例顺序。模型输出经裁剪/缩放回原图时要验证变换一致。

## 质量与性能

可按实例 IoU/AP 评估，并按目标尺寸、遮挡和拥挤程度分层。高分辨率掩码内存和带宽开销大，部署时评估精度、延迟和输出缓存；小目标边界常对下采样敏感。

## 练习与验收

对拥挤的同类目标样本输出实例可视化，检查重复、漏实例和掩码错位。报告按尺寸/遮挡切片的 AP 与推理后处理时延。

## 掩码输出到业务对象

实例分割常同时输出候选框、类别分数、系数和原型掩码，后处理需按模型定义重建每个实例掩码，再执行置信度筛选、NMS/实例匹配和原图坐标映射。明确阈值是在 logits、概率还是重建掩码上应用，避免不同实现对同一输出给出不同轮廓。

验证两个相邻同类对象、重叠遮挡、小目标和画面边缘实例；分别检查实例数、类别、掩码连通区域与边框一致性。掩码低分辨率上采样和裁剪顺序会改变边缘，需固定后处理版本。

**验收产物：**报告按尺寸/遮挡切片的实例 AP、掩码质量、输出带宽和后处理耗时，并保存预测叠图及原始张量抽样。资源不足时定义最大实例数与截断规则。
