# 实例分割

## 任务定义

实例分割既预测对象类别，也为每个对象输出独立掩码，适合需要区分相邻同类目标的场景。输出通常包含类别、置信度、边界框及像素掩码或压缩表示。

## 后处理与接口

模型可能使用候选框后处理或端到端掩码预测。要定义掩码分辨率、坐标映射、阈值、NMS/匹配策略和实例顺序。模型输出经裁剪/缩放回原图时要验证变换一致。

## 质量与性能

可按实例 IoU/AP 评估，并按目标尺寸、遮挡和拥挤程度分层。高分辨率掩码内存和带宽开销大，部署时评估精度、延迟和输出缓存；小目标边界常对下采样敏感。

## 练习与验收

对拥挤的同类目标样本输出实例可视化，检查重复、漏实例和掩码错位。报告按尺寸/遮挡切片的 AP 与推理后处理时延。
