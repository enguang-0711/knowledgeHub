# 前视 ADAS 感知开发

前视 ADAS 感知将道路图像转换成目标、车道和交通要素，为下游驾驶辅助功能提供输入。本专题关注开发链路和算法接口；功能安全与整车验证仍需按项目流程独立完成。

## 主要输出

- 车辆、行人、骑行者及其他目标的类别、边界框、置信度或轨迹。
- 车道线、道路边界或可行驶区域的图像/车体坐标表示。
- 交通标志/灯类别、状态和有效时间。
- 可选的目标距离、相对运动或道路几何信息。

每个输出都应说明坐标系、单位、采集时间、数据有效性和置信度语义。下游 FCW、AEB、LKA 等功能对延迟、稳定性和漏检模式的需求可能不同。

## 关键开发知识点

1. **远近尺度：**远距离对象像素少，输入分辨率、特征尺度和标注一致性会显著影响召回。
2. **时序稳定：**单帧检测需与轨迹关联和自车运动联系，避免框跳动、ID 切换和过期输出。
3. **道路几何：**车道输出不仅是像素曲线，还可能需映射到车体坐标并说明有效距离范围。
4. **成像变化：**逆光、隧道出入口、雨夜、污损、曝光和运动模糊可能改变数据域。
5. **接口集成：**多相机/雷达融合时，时间戳、外参、置信度和数据新鲜度必须明确。

## 调试证据

保留原始帧、实际模型输入、检测/车道输出、跟踪状态、车辆速度/姿态和下游消费结果。按采集时刻关联数据；分阶段展示延迟和失败状态，避免只看最终 HMI 判断算法根因。

## 练习与完成标准

以一个目标检测或车道线功能建立原型，按目标尺寸、距离、昼夜和遮挡分析错误；增加连续视频回放，测量轨迹/几何稳定性和输出年龄。交付接口定义、错误样例及已知场景边界。
