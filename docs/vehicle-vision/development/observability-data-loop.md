# 视觉可观测性与数据闭环

## 运行时可观测性

为每帧记录相机 ID、frame ID、采集/到达/输出时间戳、模型和标定版本、队列等待、推理时长、丢帧、无效状态与资源水位。日志要能把结果关联回原始帧，同时遵守隐私和数据保留策略。

## 问题样本回流

从误检/漏检、误跟踪、标定异常和时序问题形成候选样本，经过授权检查、去重、场景标签、人工审查和数据集版本更新后进入训练/评估。记录样本为何被选中，避免只回收模型高置信度失败。

## 发布闭环

每次模型或阈值更新都跑固定集、场景保护集、端侧性能回归和兼容性检查。灰度期间监测分层指标与资源，保留回滚制品和配置。模型收益不能以不可接受的安全场景退化换取。

## 练习与验收

模拟一个夜间漏检，从日志找到帧和版本，完成标注复核、数据集更新、基线评估和候选模型对比。证明全链路有版本和授权记录。
