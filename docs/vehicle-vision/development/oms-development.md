# 乘员监测 OMS 开发

## 功能范围

OMS 可能包含座位占用、乘员数量/位置、乘员状态、安全带或遗留物提醒。每个功能使用不同标签与错误代价，应分别定义输出、适用座位、置信度、状态更新和错误处理。

## 感知和状态推理

算法通常结合区域检测、人体姿态/属性和跨帧状态逻辑。儿童体型、毯子/衣物、背包等物品、座椅移动、遮挡和不同光照都会造成歧义。系统应能表示空座、占用、不确定和传感器无效等状态。

## 数据与隐私

建立覆盖不同人群、座椅、姿态和物品的授权数据集；标注人/物/座位归属并记录不确定样本。只收集功能所需图像并限制存储和训练用途。

## 练习与验收

实现简化座位占用识别状态输出，覆盖空座、成人/儿童、物品、遮挡和摄像头故障。报告分座位混淆矩阵和不确定状态处理。
