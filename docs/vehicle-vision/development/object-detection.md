# 目标检测

目标检测输出图像中的类别、边界框和置信度。车载场景中，小目标、遮挡、远距离和实时约束使数据定义与后处理同模型结构一样重要。

## 标签和模型输出

统一框坐标约定（如 `xyxy` 或中心点加宽高）、像素边界规则、类别 ID、忽略区域和遮挡标签。模型通常输出候选框与类别分数，之后经过置信度筛选、类别处理和 NMS 或其他去重方法。所有阈值和坐标换算均应版本化。

Anchor-based 与 anchor-free 方法在候选分配和输出方式上不同；阅读模型时关注正负样本定义、定位损失、输入尺度、多尺度特征和后处理，不要只关注模型名称。

## 评估

AP/mAP 依赖 IoU 匹配阈值、类别集合、忽略规则和评估实现。分层报告目标尺寸、距离、遮挡、天气和昼夜条件。逐样本检查漏检、误检、框偏移、重复框、类别混淆和标注歧义。

## 工程检查

- 预处理中的缩放/padding 参数是否被用于输出框反变换？
- 标签类别和评估类别 ID 是否一致？
- NMS 按类别还是跨类别执行，是否与需求相符？
- 置信度阈值对召回和误检的影响是否在目标数据上验证？
- 输入分辨率和后处理开销是否符合端侧预算？

## 练习与完成标准

用许可明确的数据跑通一个检测基线；保存预测和标注叠图、每类 AP、按尺寸切片的召回及漏检清单。手工验证若干 IoU 匹配例子，并对比部署前后框坐标映射。
