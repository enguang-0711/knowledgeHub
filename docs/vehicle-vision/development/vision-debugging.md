# 车载视觉问题调试

## 逐层定位

按传感器与 ISP、帧接入、格式/预处理、模型推理、后处理、时序/跟踪、业务接口顺序检查。为每帧保留 frame ID 和时间戳，确保故障输出能回到原图与配置。

## 关键证据

保存原始帧、处理后张量或可视化、模型/标定/配置版本、推理状态、队列深度、分段时延和资源。检查颜色顺序、归一化、尺寸变换、stride、类别表、坐标映射和时间戳语义。

## 故障分类

区分输入无效/过曝、格式错配、标注不一致、模型错误、后处理阈值、丢帧/错序、标定错误和硬件超时。一次只旁路或改变一个环节，并保留对照证据。

## 练习与验收

对固定漏检样本依次检查原图、预处理可视化、模型输出和后处理结果。注入 RGB/BGR 错配或缩放偏差，证明诊断能把根因定位到输入管线。
