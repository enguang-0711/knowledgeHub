# 图像格式与预处理

模型看到的不是“自然图像”，而是带有明确布局、颜色编码、位深和数值范围的张量。训练与端侧输入必须遵守同一预处理契约。

## 图像内存和像素格式

常见图像张量布局有 HWC（高、宽、通道）和 CHW（通道、高、宽）；视频批次还会增加时间和 batch 维。每个缓冲区都应记录宽、高、stride、平面数量、通道顺序、dtype 和有效范围。NV12 等 YUV 格式由亮度与色度平面组成，不能按 RGB 三通道图直接解释。

8-bit 像素通常在 0–255 范围，但模型可能需要 0–1 缩放或均值方差归一化。数据类型转换不会自动缩放数值。BGR/RGB 混淆、错误的 UV 偏移和 stride 假设会导致可运行但颜色错误的输入。

## 几何变换

- **缩放：**宽高比例是否保持，插值方法为何，输出尺寸如何取整。
- **裁剪：**裁剪框边界是否闭开一致，越界区域如何填充。
- **Padding/letterbox：**上下左右的填充值和偏移要保存，以便把模型输出映射回原图。
- **翻转/仿射/透视：**图像和标签必须使用同一个变换矩阵。
- **归一化：**通道顺序、均值/方差和计算精度必须与训练配置一致。

检测框和关键点在变换后必须同步变换；分割掩码通常应使用不会产生新类别的插值方式。不同变换可能需要不同插值，需按任务验证。

## 图像增强

亮度、对比度、色彩、模糊、噪声、遮挡和几何增强可以扩大训练样本变化，但不应无依据地模拟相机物理过程。增强后要检查边界、标签和样本语义是否仍然有效，并记录增强配置和随机种子。

## 调试方法

对同一帧保存原图、模型输入张量的可视化、变换参数和输出坐标。先比对预处理图，再比较模型张量数值；只看最终检测框不容易发现颜色和缩放错误。准备一组固定“金样本”验证 Python 与 C++ 预处理结果。

## 练习与完成标准

实现 RGB/BGR、resize、padding、归一化和输出坐标反变换；用非方形图像、奇数尺寸、越界框和不同 stride 样例验证。Python 与部署实现对同一输入的张量误差应在明确阈值内，并能说明比较方法。
