# 视觉代码与数据版本管理

## 版本边界

源码、构建脚本、schema 和轻量配置纳入 Git；图像/视频数据、标注集和模型由合适的数据/制品仓库保存。代码提交中保留数据版本 ID、manifest 路径、哈希和获取说明，避免把大型或受限原始数据直接提交。

## 实验追踪

每个训练/部署结果绑定代码提交、数据与标注版本、预处理、模型权重、类别映射、标定、工具链和硬件。版本更新生成可比较差异，不覆盖已发布制品。

## 评审重点

评审中检查 schema/类别变更、数据许可、标定影响、固定集回归和回滚方案。密钥、个人图像和位置数据不得进入普通仓库或公开 CI 日志。

## 练习与验收

完成一次数据集新增和模型更新，生成新 manifest 并保留旧版本。另一位开发者能根据记录重建相同训练/评估样本。
