# 环视成像与鸟瞰图开发

## 多相机链路

环视系统从多路相机采集、畸变校正、外参投影和地面映射生成鸟瞰图。相机安装、内外参、同步、曝光和图像链路共同决定拼接几何，必须使用相同的标定和帧身份。

## 投影与融合

将每路鱼眼/广角图像映射到地面或鸟瞰网格，并在重叠区做接缝/亮度融合。路面高度变化、坡道、非地面物体和相机盲区会造成拉伸、断裂或重影，拼接并非单纯图像拼接问题。

## 工程约束

处理多路分辨率、缓冲与同步时延，报告拼接接缝、网格位置误差、帧率和显示延迟。摄像头掉线或标定不匹配时应显示失效状态，不能保留误导性的旧 BEV 帧。

## 练习与验收

用地面网格估计并验证四路投影，检查已知点落在 BEV 的位置。注入外参偏差和一路冻结，说明误差与失效检测方式。

## 环视图像链路调试顺序

先对每路相机分别验证曝光、畸变、分辨率、时间戳和标定身份，再构造去畸变映射、地面投影和 BEV 范围；此时使用已知尺寸网格检查几何，再加入重叠区融合、亮度补偿和车身遮罩。把拼接图与每路原图保留在同一 frame ID 下。

鱼眼地面投影依赖地平面假设，车、人等非地面物体可能拉伸或分裂；动态场景还会暴露同步偏差。为各类伪影明确期望行为，不能只以“接缝看起来平滑”作为通过标准。

**验收产物：**交付相机/标定配置、地面网格误差、接缝/重影/盲区样例、端到端延迟和单路故障行为。相机失效时显示区域应明确标为不可用，不能由其他画面填充成误导性的完整鸟瞰图。
