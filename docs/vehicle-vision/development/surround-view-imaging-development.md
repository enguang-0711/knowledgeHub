# 环视成像与鸟瞰图开发

## 多相机链路

环视系统从多路相机采集、畸变校正、外参投影和地面映射生成鸟瞰图。相机安装、内外参、同步、曝光和图像链路共同决定拼接几何，必须使用相同的标定和帧身份。

## 投影与融合

将每路鱼眼/广角图像映射到地面或鸟瞰网格，并在重叠区做接缝/亮度融合。路面高度变化、坡道、非地面物体和相机盲区会造成拉伸、断裂或重影，拼接并非单纯图像拼接问题。

## 工程约束

处理多路分辨率、缓冲与同步时延，报告拼接接缝、网格位置误差、帧率和显示延迟。摄像头掉线或标定不匹配时应显示失效状态，不能保留误导性的旧 BEV 帧。

## 练习与验收

用地面网格估计并验证四路投影，检查已知点落在 BEV 的位置。注入外参偏差和一路冻结，说明误差与失效检测方式。
