# 车载视觉专题

车载视觉专题分成开发和测试两条独立内容线。开发侧学习怎样构建图像处理、感知算法、模型和车端服务；测试侧学习怎样验证成像链路、数据质量、场景覆盖、模型指标和 ECU 行为。

| 内容线 | 学习目标 | 入口 |
|---|---|---|
| 开发 | 从编程、图像几何和视觉算法基础走到训练、部署、系统集成，形成可运行的算法或车端功能 | [开发学习路线](/vehicle-vision/development/roadmap) · [开发知识点目录](/vehicle-vision/development/) |
| 测试 | 从摄像头与数据质量走到指标、ODD 场景覆盖、仿真回放和 ECU 回归，形成可复现的验证证据 | [测试专题导览](/vehicle-vision/testing/) · [测试学习路线](/vehicle-vision/testing/roadmap) |

开发专题文档集中在 `development/`，测试专题文档集中在 `testing/`。两者共享通用工程能力，各自维护领域知识、数据口径、工具和验收目标。

交互式模型：[ADAS 前视相机标定台 3D 展示](/vehicle-vision/development/adas-calibration-3d)（偏航、俯仰与针孔投影的教学演示）。

交互式模型：[环视泊车验证台 3D 展示](/vehicle-vision/development/surround-view-parking-3d)（四路环视视锥、泊车场景与 BEV 示意）。

交互式模型：[前视 ADAS 道路验证台](/vehicle-vision/development/adas-road-3d)（前车跟踪、相邻车切入、遮挡行人与几何真值距离）。

交互式模型：[驾驶员监测 DMS 座舱试验台](/vehicle-vision/development/dms-cabin-3d)（座椅位置、驾驶员眼睛与近红外相机的几何关系，以及四类已知输入标签）。
