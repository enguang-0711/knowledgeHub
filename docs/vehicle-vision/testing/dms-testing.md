# 驾驶员监测（DMS）测试

## 功能边界

DMS 可包含视线/头姿、闭眼/疲劳、分心、遮挡和驾驶员存在检测。测试前确认功能定义、输出事件、阈值、触发持续时间、告警策略、适用人群和失效状态。

## 场景维度

覆盖驾驶员身高/坐姿、眼镜/墨镜、帽子、口罩、面部遮挡、昼夜、逆光、眼部反射、摄像头偏移和道路振动。关注不同人群和条件下的误报/漏报差异，遵循隐私和公平性要求。

## 证据与评估

使用标注视频、事件时间戳、告警记录和摄像头状态证明检测行为。报告事件级召回、误报率、检测延迟和失效识别，切片到遮挡/光照/群体条件。

## 练习与验收

选闭眼提醒功能，建立正常、短闭眼、长闭眼、墨镜和遮挡用例。记录告警时刻和事件真值，并验证摄像头遮挡时系统正确报告无效状态。
