# 视觉仿真测试

## 仿真适用范围

仿真可大规模构造可控场景、极端条件和罕见组合，适合早期算法比较与场景边界探索。其结果受渲染、传感器模型、材质、光照、动态行为和标签生成质量限制，不能自动等同真实道路表现。

## 场景与参数

固定仿真器版本、地图、天气/光照、传感器模型、随机种子、对象行为和脚本。使用参数扫描或场景变体覆盖边界，并记录渲染帧、真值和执行配置。

## 仿真可信度

将仿真和实采数据在图像统计、目标外观、运动、噪声及算法错误分布上比较。针对关键场景进行实车/封闭场地对照，维护已知模拟偏差清单。

## 练习与验收

创建一个遮挡或逆光场景变体集，固定随机种子并导出真值。检查仿真器升级后图像与标签差异是否超出容差。
