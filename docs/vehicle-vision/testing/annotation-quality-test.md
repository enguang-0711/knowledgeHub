# 视觉标注质量测试

## 规范与样本抽查

在标注前冻结类别 schema、框/多边形边界、遮挡/截断、忽略区、车道线拓扑和跟踪 ID 规则。抽样检查应覆盖类别、难例、视频片段和标注员，而不是只抽容易样本。

## 一致性指标

可比较框 IoU、类别一致率、分割边界 IoU、关键点距离、轨迹 ID 连续性及双人标注仲裁率。数值指标要结合任务容差解释，不能把单个一致率当成标签正确性的充分证明。

## 自动校验

检测空框、越界坐标、非法类别、重复 ID、不连续时间戳和图像尺寸不匹配。对时序标签检查轨迹跳变和不可能速度，生成可视化审查队列。

## 练习与验收

双人标注同一短片并建立差异报告，按规范仲裁。提交错误类型统计、修订后的标签版本和工具/规范记录。
