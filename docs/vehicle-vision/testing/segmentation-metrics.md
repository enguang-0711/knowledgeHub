# 视觉分割指标测试

## 区域指标

按类别计算 IoU、Dice、mean IoU 和像素准确率；报告类别支持数和忽略像素规则。mean IoU 对类别等权，像素准确率则容易被大面积类别主导。

## 边界和实例

对道路边缘、车道线或精细轮廓，应增加边界距离、容差带内精度/召回等指标。实例分割需明确实例匹配和 AP 口径，不能将语义掩码指标套用到实例输出。

## 工程检查

验证输出分辨率、上采样方式、类别 ID、调色板和裁剪映射。将预测与真值叠加，重点审查细小结构、遮挡边界和相邻区域混淆。

## 练习与验收

构造类别面积差异明显的样本，比较像素准确率与 mean IoU。输出每类指标、边界错误案例和忽略规则。

## 指标实现核对

评估前冻结类别表、ignore index、空类计分方式、像素边界和图像还原变换。用手工掩码核算 IoU/Dice，确认混淆矩阵是在像素级累积还是逐图平均；mean IoU 的空类别处理会显著改变结果。

道路边界、车道线等任务要增加边界容差指标；实例掩码则使用实例匹配/AP，不能将语义分割公式直接套用。**验收产物**包括每类指标和支持像素、边界/小目标切片、叠加图及评估脚本版本，并单独审查忽略区域和类别映射。
