# 车载相机标定测试

## 检查内容

确认标定参数与相机序列号、镜头、分辨率、裁剪、安装位置和车辆配置匹配。检查内参/畸变、外参方向、坐标约定、单位、标定时间和有效范围。

## 数值与可视化验证

评估重投影误差均值、分位数和空间分布；观察边缘残差、标定板覆盖、角点检测和多相机重叠。将车辆坐标轴、地面网格或已知目标投影回图像，检查实际几何是否合理。

## 稳定性和失效

测试温度、振动、维修换件和配置升级后的标定有效性。缺失、损坏或与硬件不匹配时，系统应明确拒绝/降级并上报状态，不能静默使用默认值。

## 练习与验收

对一组标定图重新估计参数并与基线对比。人为替换另一相机的标定文件，验证身份校验能够检测错配。
