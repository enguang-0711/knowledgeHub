# 环视、泊车影像与泊车感知测试

环视/泊车视觉的核心难点是**多相机几何与时间一致性**。单路相机画面看起来正常，不代表拼接后的鸟瞰图准确；拼接图好看，也不代表车位、障碍物和距离输出满足功能需要。本专题与前视 ADAS 的目标检测指标分开定义。

## 术语拆解

- **AVM（Around View Monitor）**：全景环视监视系统，通常将车身周围多路广角相机画面变换并拼接成俯视/鸟瞰显示。
- **鱼眼/超广角相机**：视场角大、畸变显著的成像设备，需匹配相机模型和去畸变参数。
- **鸟瞰图（BEV, Bird's-Eye View）**：把相机图像映射到地面平面附近的俯视表示；高度不在地面上的物体会产生投影偏差。
- **接缝（seam）**：相邻相机重叠图像融合的边界；几何、亮度、颜色或时间不同步时会出现断裂/双影。
- **泊车感知**：可能输出车位线/车位角点、障碍物、车身周边占用、可行驶区域或距离；具体取决于产品方案。

## 一、典型链路和被测输出

```text
前/后/左/右相机 → 各路 ISP 与时间同步 → 镜头校正
→ 标定与地面映射 → 图像拼接/融合 → BEV/HMI
→（可选）车位/障碍物感知 → 泊车功能状态与提示
```

记录相机数量和安装位、相机/ISP 型号、分辨率、同步方式、标定 ID、映射表版本、车身尺寸配置、拼接策略、车位/障碍物协议及 UI 版本。说明测试输入经过真实摄像头、视频回放、图像接口还是渲染结果；后两者可能绕过 ISP、同步和摄像头链路。

## 二、标定与 BEV 几何

每路相机先独立检查视野、畸变模型和有效区域，再验证相机之间的外参。地面映射通常以地面近似平面为前提；墙、柱、儿童、路沿等有高度的物体投到地面时会发生偏移。因此，标定靶标要覆盖前后左右、近车/远车、重叠区域和画面边缘，不能只测中心点。

建议检查：

1. 图像角点/直线在去畸变前后的合理性，边缘是否过度拉伸或裁切。
2. 已知长度地面网格的纵横尺度、方向、弯曲和位置误差。
3. 相邻相机重叠区的目标位置、线条连续性、亮度/色差与双影。
4. 车身模型（车辆轮廓、保险杠、后视镜等）与真实投影的对齐及遮挡盲区。
5. 标定重复性：拆装、温度、车辆载荷或摄像头支架变化是否影响关键区域。

图像“拼缝可接受”要按业务要求制定判据，例如地面线错位、关键目标错位或有效视野遮挡；不应用主观观感替代可测指标。不同高度物体在接缝两侧出现形变，可能是平面投影的固有限制，也可能是标定/融合问题，要用多位置、多高度测试点分辨。

## 三、图像质量与显示检查

检查各路色彩/亮度差异、曝光切换、暗部噪声、雨滴污渍、镜头遮挡、压缩伪影、帧冻结、花屏、黑屏、画面延迟和切换瞬间闪烁。显示 UI 还要看车辆图标方向、挡位/速度条件、辅助线、视图切换、图层遮挡、分辨率缩放和不同屏幕布局。

若通过 OCR 或截图比对断言 UI：为动态/抗锯齿区域设置合理掩膜；对标定线、警示区域、车辆模型等关键图形设计专门的几何断言；截图对比需绑定屏幕分辨率、渲染版本和采集时刻。纯像素完全相等对动态画面往往过于脆弱。

## 四、车位与障碍物测试

对于车位检测，定义车位类型、角点/线段表达、可见性、遮挡、斜列/垂直/平行等类别、车位边界和真值测量方式；指标可包括车位检出率、误检率、角点/线段距离误差、朝向误差以及稳定性。对于障碍物，定义类别、近车距离、可见高度、遮挡和车身坐标系位置；小型/低矮物体、路沿、立柱、墙角和悬空物需分层。

测试感知输出时，不要用 HMI 截图代替结构化结果；测试 UI 时，不能只看模型输出。分别断言检测结果、提示/颜色/距离标记、泊车状态和总线事件，验证时间戳关联。低速泊车功能若改变车辆运动，应在获批准的模拟器/台架或场地测试计划下执行。

## 五、场景和边界

覆盖不同路面材质/颜色、地面纹理、标线褪色、反光、积水、坡面、车位线遮挡、临时物体、相邻车辆大小/颜色、墙柱距离、行人/儿童、夜间照明、逆光、相机污损、车辆载荷/姿态与转向视角。还应验证无效相机、单路掉线、相机错接、时间戳错位、标定版本错配和切换视图时的故障提示/降级行为。

## 常见重难点

- **接缝重影**：检查多路时间戳、运动目标、标定和融合权重；静态场景正常不代表运动中正常。
- **画面几何在边缘偏差大**：确认鱼眼模型、有效区域、裁切和安装参数；检查是否只用中心样本拟合。
- **地面投影看起来合理但障碍物位置不准**：高度造成视差，需在不同高度目标上单独验收。
- **UI 图片测试易误报**：控制环境、遮罩动态区域，并把状态文字、图形位置、颜色和结构化信号分开断言。
- **四路相机各自通过但整体失败**：检查相机 ID 映射、同步帧组、车身坐标约定和整车配置绑定。

## 动手练习与验收

用合成四路图或许可明确的公开样例制作环视验证集：建立相机/帧组 manifest；覆盖已知地面网格和一处高度目标；生成拼接图与接缝误差可视化；实现帧冻结、相机缺失和同步偏移检查；写明哪些结论只能在实车标定后确认。验收产物应包含配置版本、位置点误差表和可重放输入。
