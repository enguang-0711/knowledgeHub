# 视觉视频回放测试

## 回放目的

视频回放让同一图像序列可重复经过软件链路，适用于算法回归、故障复现和版本比较。它通常不能覆盖真实传感器曝光、ISP 实时行为、硬件触发和物理环境，报告要明确实际经过的链路。

## 时间与输入

保留原始帧率、帧 ID、时间戳、相机配置和标定版本。回放可按原始速率、加速或单步运行，但需标明模式；不得用固定 sleep 模拟精确时序。记录丢帧、重复帧和缓冲策略。

## 判定

关联每帧输入、模型输出和期望结果。除离线精度外，检查处理时延、队列行为、状态初始化和跨帧跟踪。重复执行同一版本应得到可解释且符合确定性要求的结果。

## 练习与验收

建立带 manifest 的视频回放器，支持暂停、单步和结果保存。重复运行后比较帧数、时间戳、输出摘要和差异帧。
