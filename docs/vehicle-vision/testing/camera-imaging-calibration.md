# 摄像头成像、几何与标定

本页解释图像如何由车载摄像头产生，以及怎样验证相机几何关系。视觉模型只看到经过镜头、传感器和 ISP 处理后的像素；图像变差或坐标系出错时，单看模型分数无法定位问题。

## 学习目标与先修

读完应能解释图像采样和曝光参数、区分内参与外参、把像素坐标与车体坐标关联起来，并设计一份可以复现的相机标定检查记录。

先修：二维/三维坐标、矩阵乘法、图像像素和基本线性代数。不需要先学深度学习。

## 数字成像：从光线到像素

### 图像传感器和曝光

镜头把场景投影到传感器，像素阵列在曝光时间内积累光电子，再由读出电路和模数转换得到数字值。图像值并非场景亮度本身：曝光时间、模拟/数字增益、光圈、传感器响应和 ISP 都会参与变换。

- **曝光时间**：单帧积分光线的时间。越长通常越亮，也更容易产生运动模糊。
- **增益**：放大传感器信号。提高增益可以抬高暗部，也会放大噪声或降低有效动态范围。
- **动态范围**：同一帧可保留的亮暗范围。逆光下若亮部饱和，暗处目标可能丢失细节。
- **滚动快门**：逐行读取，不同行对应的采样时刻不同；快速运动或车辆振动会产生倾斜/形变。
- **全局快门**：各像素近似同时曝光，动态几何更稳定，但器件成本、分辨率和灵敏度取舍由系统决定。
- **帧率**：每秒采集帧数。标称帧率不等于有效帧率；时间戳间隔、丢帧和缓冲排队都要实测。

### ISP 和像素格式

ISP（Image Signal Processor，图像信号处理器）可能执行去马赛克、降噪、白平衡、色彩变换、畸变校正、HDR 合成和缩放。量产感知模型的输入可能是 RAW、YUV 或 RGB 张量；数据通道顺序、位深、色彩范围、裁切和归一化必须与模型预处理一致。

常见错误包括 RGB/BGR 通道互换、YUV full/limited range 混淆、宽高顺序反转、错误 resize 插值和归一化均值/方差不匹配。这些错误能让单元测试“成功推理”，却使结果整体退化。

**重难点：**要分开验证原始传感器质量、ISP 输出和模型输入张量。离线 PNG/JPEG 可能已经经过压缩、裁切和色彩处理，不能代表相机原始链路。

## 针孔相机模型和内参

在理想针孔模型中，三维相机坐标点 `X_c = (X, Y, Z)` 投影到像素近似为：

```text
x = X / Z,  y = Y / Z
u = f_x · x + c_x
v = f_y · y + c_y
```

`f_x`、`f_y` 是以像素表示的焦距，`(c_x, c_y)` 是主点。写成矩阵时，内参矩阵 `K` 将归一化成像平面映射到像素坐标。实际镜头有径向/切向畸变，必须使用对应镜头模型和畸变参数校正，尤其是广角/鱼眼环视相机。

内参会受镜头焦距、对焦、分辨率和裁切模式影响。更换分辨率或 ISP 裁切配置后，不能假设旧内参仍适用。

## 外参、坐标系与误差传播

外参描述相机相对车辆、IMU、雷达或其他相机的位置和朝向。刚体变换通常写成 `X_vehicle = R · X_camera + t`，其中旋转矩阵 `R` 和平移向量 `t` 必须明确变换方向、坐标轴正方向、单位和参考原点。

常见坐标系包括：图像像素坐标、相机坐标、车体坐标、地面/世界坐标。不同团队可能采用不同的轴向约定，文档中必须画图或明确轴定义。近似地面投影可使用单应矩阵，但只对满足平面假设的点有效；有高度的车辆/行人不能直接按地面单应变换推导真实三维位置。

小角度外参偏差会随目标距离和投影位置放大。标定误差不能只看“画面大致对齐”；需要测量关键位置处的像素/几何偏差，并沿实际使用链路评估它对距离、车道偏移或环视拼接的影响。

## 标定方法和质量检查

1. 固定相机型号、镜头、安装位置、分辨率、焦距/对焦、目标距离和照明；任何变更都生成新的配置版本。
2. 使用已知尺寸的棋盘格、圆点板或项目认可靶标，采集覆盖图像中央、边缘、不同距离和倾角的样本。
3. 求解内参/畸变，检查每张图的角点质量、重投影误差、残差分布和异常帧。
4. 对车辆外参使用明确的车体基准和测量流程，记录靶标位置、姿态、单位和变换方向。
5. 用未参与求解的验证帧或独立测量点复核，避免只在训练/求解样本上看误差。
6. 重复拆装/多次采集，估计可重复性；保存校准设备、操作者、日期和软件版本。

重投影误差可用标定点观测像素位置 `p_i` 与模型投影 `p̂_i` 的距离计算，例如均方根误差 `RMSE = sqrt(mean(||p_i - p̂_i||²))`。必须注明统计的是角点还是靶标、像素坐标还是归一化坐标，以及异常帧处理方法。误差低并不自动证明外参坐标方向正确，也不证明整车目标距离准确。

### 环视特有的检查

每个摄像头单独检查畸变和覆盖视野，再验证多路相机时间同步、重叠区域、鸟瞰变换、地面尺度、拼接缝和车身遮挡。使用尺寸已知的地面网格/标记，从车辆周围多个方位检查等距线、直线弯折、近车区域拉伸和盲区。不要只用静态中央区域的一张图验收。

**学习卡片**

- **易混点：**内参描述成像几何；外参描述传感器之间的刚体关系。图像校正矩阵又是另一个派生配置。
- **常见误区：**对着训练用靶标的低 RMSE 就认为全视野无偏差；把地面单应当作通用三维投影。
- **先修与练习：**用 OpenCV 标定公开样例；改变分辨率/裁切后验证旧 K 矩阵是否还成立；输出残差热图和版本清单。
- **学习资料：**[OpenCV 相机标定](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)、[ROS REP-103 坐标约定](https://www.ros.org/reps/rep-0103.html)、[B 站：针孔模型、相机内外参与标定误差](https://search.bilibili.com/all?keyword=%E9%92%88%E5%AD%94%E7%9B%B8%E6%9C%BA%E6%A8%A1%E5%9E%8B%20%E5%86%85%E5%A4%96%E5%8F%82%20%E6%A0%87%E5%AE%9A%E8%AF%AF%E5%B7%AE)。

## 可复现检查清单

每次相机成像/标定测试保存：相机/镜头序列号或匿名 ID、安装位置、车辆配置、传感器与 ISP 版本、输入格式、曝光/HDR 配置、内外参版本、靶标与采集姿态、温度/照明、原始帧哈希、时间戳、误差算法、阈值来源和验证结果。阈值由产品需求、系统误差预算和重复性实验确定，不把教程示例数字直接当量产门槛。
