# 车载视觉场景矩阵

## 场景维度

从功能和风险识别道路结构、目标类型/尺寸、距离、遮挡、光照、天气、速度、相机状态、交通参与者行为和软件状态等维度。避免把所有维度直接做笛卡尔积；按风险、代表性和交互作用选择组合。

## 覆盖度量

为场景定义标识、参数范围、覆盖目标、样本数量、执行状态和结果。可报告类别/边界覆盖、风险权重覆盖、成对组合覆盖及真实道路/仿真来源。覆盖百分比需说明分母和未覆盖风险。

## 场景资产

每个场景关联视频/图像、标签、ODD 状态、环境元数据、预期输出和复现步骤。合成场景要验证物理合理性和标签一致性，并通过实采样本校准差异。

## 练习与验收

为夜间行人检测建立场景矩阵，优先覆盖远距离、逆光、部分遮挡和雨夜组合。给出风险排序、已覆盖/缺失场景和新增数据计划。

## 风险驱动的矩阵构建

先从功能失效和危害列出场景因子、取值范围、边界、交互关系及风险权重；再用代表性组合、成对组合和高风险组合控制规模，不必枚举所有笛卡尔积。每个场景关联需求 ID、ODD 状态、数据/仿真来源和预期输出。

**验收产物：**矩阵报告给出覆盖分母、已执行/通过/失败/阻塞数量、未覆盖高风险项和补齐计划。场景标签要能从日志或数据 manifest 找回；新增组合需说明为何重要，以及由仿真、回放还是台架执行。
