# 视觉分类指标测试

## 混淆矩阵

分类评估从冻结的类别顺序和真值标签构造混淆矩阵。报告每类 precision、recall、F1、支持样本数和宏/微平均口径。类别不均衡时 accuracy 可能看似很高，却掩盖少数类完全失效。

## 阈值和拒识

多标签或带置信度阈值的场景需要测试阈值变化、未知类和低置信输出。阈值应在验证集选择，并在独立测试集报告。关注误报和漏报的业务代价。

## 切片分析

按光照、遮挡、距离、相机、天气和目标尺寸切片。确保标签映射与模型类别顺序相同，并验证空预测、未知标签和无效帧的处理。

## 练习与验收

对固定样本计算混淆矩阵和宏/微 F1，人工复核边界错例。输出类别表版本、样本数及脚本版本。

## 指标复核流程

固定类别顺序、未知类/忽略样本策略和阈值来源；先用人工构造的真阳性、假阳性、漏检和错类样本检查混淆矩阵计数，再在冻结测试集计算每类指标。宏平均、微平均和加权平均要分开标注，避免不同脚本的默认口径混用。

**验收产物：**提供混淆矩阵原始计数、每类 precision/recall/F1 与支持数、置信阈值/校准版本及按场景切片的样本索引。复核少数类和拒识边界；总 accuracy 上升但关键类 recall 下降时，应按产品风险明确判定。
