# 多摄像头同步测试

## 时间戳语义

确认每路相机时间戳代表曝光、帧完成还是入队时刻，并记录时钟域和精度。主机到达时间不能自动代表曝光时间；系统时钟调整也可能造成时间回跳。

## 测试方法

用同时可见的闪光/运动目标或硬件触发标记测量曝光偏差，统计跨相机时间差、抖动、迟到、缺帧和重复帧。分别在启动、温度变化、长时运行和设备重连后测量漂移。

## 融合影响

检查融合模块实际使用的帧 ID 和时间差。制造可控偏移，观察 BEV 接缝、目标位置和跟踪状态变化，确定最大允许时间差和超限策略。

## 练习与验收

对双相机录制计算时间差分布，模拟一路丢帧和时钟跳变。报告同步误差、配对率和系统采取的拒绝/降级动作。

## 量测方案与故障注入

用公共闪光源或同步运动标记记录多路曝光，在相同 frame ID/事件窗口内计算偏差；分别统计启动瞬间、稳定运行、热状态变化、重连及长时间漂移。记录触发信号、曝光时刻定义、时钟域和测量设备误差。

注入一路丢帧、重复帧、迟到帧和时钟回跳，验证同步器是否按容差拒绝或降级，并检查下游融合没有配错帧。**验收报告**包含偏差分位数、配对率、超限帧索引、漂移曲线和恢复时间，门槛来自具体融合需求而非任意通用值。
