# 视觉 SIL 与 HIL 测试

## 测试层级

SIL（软件在环）在主机/仿真环境验证算法与软件逻辑；HIL 将目标 ECU 接入受控信号或传感器仿真，可覆盖真实硬件、驱动和调度的一部分行为。二者均有明确覆盖边界，不能互相替代所有道路验证。

## 环境与同步

固定主机/ECU、固件、驱动、编译选项、摄像头或视频源、仿真器、标定和网络配置。关联输入帧、传输事件、推理输出与系统日志的时间戳，检查回放速率和硬件调度影响。

## 故障注入和恢复

测试断流、帧冻结、信号延迟、丢帧、过温、设备重置和推理超时。检查错误状态是否被报告、输出是否标记无效、恢复后状态是否干净。

## 练习与验收

在可用的 SIL/HIL 环境回放固定视频并注入断流。提交配置清单、输入输出关联、故障证据和恢复结论。

## SIL/HIL 执行与对齐

SIL 先验证算法、状态逻辑和确定性回放；HIL 增加目标处理器、驱动、实际调度和接口时序。测试记录软件/固件、编译选项、仿真源、摄像头/回放格式、时钟同步和标定，逐帧关联输入、输出和日志。

通过断流、冻结帧、延迟/乱序、过温或推理超时检查检测、上报、降级和恢复。**验收产物**应明确覆盖边界、台架配置、故障注入时间线、恢复时长和失败证据；环境搭建失败要标记为阻塞，不能记作产品通过。
