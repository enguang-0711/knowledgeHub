# 视觉 ECU 性能测试

## 测量对象

端到端测量包括采集/传输、预处理、推理、后处理、队列等待和业务输出。定义每个时间戳的时钟域和测量边界，分别测冷启动、稳态、多路并发与温度稳定后的性能。

## 指标

报告 p50/p95/p99 延迟、帧率、丢帧率、队列深度、CPU/NPU 利用率、内存峰值、带宽、功耗和温度。平均 FPS 可能掩盖周期性卡顿与输出延迟，应同时观察长尾和持续运行趋势。

## 负载与热状态

模拟目标路数、显示/记录/网络负载和后台任务。长时间运行以检查热降频、内存增长、资源泄漏和性能漂移；记录环境温度、散热条件及电源状态。

## 练习与验收

对固定模型和视频流运行稳态及多路压力测试，输出分段时间线与资源曲线。确认精度版本一致，并给出性能预算余量。

## 可重复的性能测量

固定输入帧率、分辨率、模型/标定、并发路数和系统后台负载；分开记录冷启动、预热和稳态数据。每帧测采集至输出的端到端时间，并用同一时钟记录预处理、排队、推理、后处理阶段，避免把 GPU/NPU 异步提交时间误当完成时间。

**验收产物：**至少给出样本量、p50/p95/p99、超时/丢帧率、队列深度、CPU/NPU、内存、功耗和温度曲线。重复运行并标注散热与环境条件；超预算时定位阶段和热降频证据，不能只报告平均 FPS。
