# 环视影像测试

## 成像与拼接

环视测试覆盖多路摄像头成像、标定、畸变校正、地面投影、接缝融合和显示链路。固定摄像头/镜头/安装、标定、图像格式和显示配置，测试前核对各路输入有效。

## 图像质量

检查拼接错位、重影、亮度/颜色差、接缝突变、遮挡盲区、地面网格变形和延迟。使用地面标记、直线/网格和已知障碍物对比左右/前后映射；边缘区域应单独检查。

## 显示与状态

检查视图切换、倒车/泊车状态触发、图像冻结、摄像头掉线、黑屏和延时提示。确认显示帧可追溯对应相机输入，避免旧帧仍显示为当前视图。

## 练习与验收

用地面网格和多个已知点验证拼接位置，再注入一路摄像头黑屏。提交各路原图、BEV/显示结果、标定版本和失效提示证据。
