# 乘员监测（OMS）测试

## 功能边界

OMS 可包含座位占用、乘员数量/位置、安全带状态、遗留儿童或物品提醒等能力。不同功能的标签、风险等级和允许传感器不同，测试计划要分别定义，不把“乘员检测”当成单一目标。

## 场景覆盖

覆盖不同座位、儿童/成人体型、姿态、遮挡、衣物/毯子、空座物品、光照和多人场景。对涉及儿童或安全带提醒的功能，应特别检查漏报与误报代价和系统状态反馈。

## 数据与隐私

使用授权数据，最小化保存可识别图像。验证脱敏、访问控制和删除要求。标签协议需区分人体、物品、座位归属和不确定状态。

## 练习与验收

建立空座、成人/儿童乘员、遮挡物品和座位变化测试集，按功能输出混淆矩阵和事件级错误。检查未知/遮挡状态不会被误报为确定占用结论。
