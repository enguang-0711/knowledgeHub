# 目标检测指标测试

## 匹配与 AP

检测评估按类别和 IoU 阈值将预测框与真值框匹配，再计算 precision-recall 曲线与 AP。需冻结 IoU 定义、边界坐标约定、置信度排序、忽略区域、重复框和最大检测数规则。

## 场景切片

报告 mAP 同时按目标大小、距离、遮挡、类别、天气、光照和相机切片。检查小目标、远距离和稀有类别表现；平均值可能掩盖关键安全目标退化。

## 输出契约

测试类别 ID、坐标映射、分数范围、NMS 和无效帧行为。可视化用于找出框偏移、类别映射和重复预测问题，但最终结论应基于固定脚本和版本化真值。

## 练习与验收

手工构造正确、错类、重复框和漏检样例，验证匹配器输出。报告指标版本、每类 AP 与典型错误。
