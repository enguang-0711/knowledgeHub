# 多目标跟踪指标测试

## 评测内容

跟踪同时评价检测与跨帧身份关联。常见指标包括 HOTA、IDF1、MOTA，以及 ID switch、轨迹碎片、漏跟踪与误跟踪。不同指标强调的错误不同，报告需给出实现和参数版本。

## 序列条件

冻结帧率、时间戳、真值 ID 生命周期、忽略区和序列边界。测试遮挡后重现、交叉、进出视野、摄像头抖动、丢帧和时间间隔变化。按目标类别、距离和遮挡分层。

## 诊断

同时保存检测输出与轨迹可视化，区分检测漏失、关联错误、跟踪状态管理和输入时序问题。分析 ID switch 发生帧及关联代价，而不仅是最终总分。

## 练习与验收

使用带真值 ID 的短序列计算跟踪指标，注入丢帧并观察轨迹碎片与身份切换变化。报告序列长度和评测器设置。

## 逐序列评估与根因分离

冻结检测器输出、帧率/时间戳、真值 ID 生命周期、忽略区和评测器版本；先抽取短序列手工检查匹配，再对全序列计算 HOTA/IDF1/MOTA 及 ID switch、轨迹碎片和漏跟踪。不同指标不能合并成一个“跟踪准确率”。

按遮挡、交叉、远距离、出入画和丢帧切片，联看检测框与轨迹 ID，找出身份切换前后帧。**验收产物**应包含序列级分数、失败片段索引、匹配参数和丢帧实验对照，区分检测失败、关联失败及时序输入问题。
