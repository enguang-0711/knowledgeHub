# 车载相机成像测试

## 测试对象

相机成像测试覆盖传感器、镜头、曝光/增益、ISP、像素格式和图像链路。测试前冻结相机型号、镜头、固件、ISP 配置、分辨率、帧率、曝光策略和安装位置。

## 图像质量维度

检查清晰度、噪声、动态范围、曝光、白平衡、颜色、畸变、眩光、鬼影、滚动快门、坏点和帧稳定性。按白天/夜晚、逆光、隧道、雨雾、污渍和温度变化设计场景，观察算法输入实际图像而非只看显示器截图。

## 可复现方法

记录照度/目标、相机到目标距离、光源方向、曝光参数和采集时间。使用测试图卡可验证分辨率、颜色和畸变；真实道路场景用于补充动态与域内效果。保留原始数据和相机元信息。

## 练习与验收

比较两个 ISP 配置的昼夜图像，给出质量指标和典型帧。验证输出像素格式、stride、帧率与声明一致，并能关联相机与配置版本。
