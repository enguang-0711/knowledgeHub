# 视觉数据集版本测试

## 版本完整性

数据集清单应引用稳定样本 ID、原始文件哈希、标注版本、来源、采集条件、授权状态和排除原因。发布时校验文件缺失、重复、解码失败、无效标注及清单与实体文件不一致。

## 切分泄漏

相邻视频帧、同一驾驶片段、同一车辆/采集日可能高度相关。测试切分策略是否按适当群组隔离，并用感知哈希、时间戳和采集元数据检查跨集合近重复。

## 可重现性

冻结 manifest、预处理和采样逻辑后，应能重建完全相同的训练/验证/测试样本。变更数据或过滤规则时生成新版本并比较场景分布。

## 练习与验收

构造含重复帧、缺文件和跨集合片段的数据集，编写校验器识别问题。输出清单差异和可复现报告。
