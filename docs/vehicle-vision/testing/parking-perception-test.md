# 泊车感知测试

## 被测输出

根据系统能力明确车位线/车位角点、障碍物、可行驶区域、可用泊车位和规划接口。坐标系、置信度、更新时间、无效状态和目标生命周期都需有可验证契约。

## 场景与真值

覆盖标准/斜列/垂直车位、线条磨损、阴影、地面反光、坡道、路沿、柱子、低矮障碍物、相邻车辆遮挡和动态行人。真值测量需注明参考坐标和测量误差。

## 功能判定

分别评估感知准确性、泊位可用性判断和业务状态转换。错误车位、漏掉低矮障碍物、重复候选和输出延迟的业务风险不同，要单独分析。仿真、录制回放和实车台架覆盖范围应分开标识。

## 练习与验收

选一组受控低速场景，建立泊位真值并检查输出坐标和可用性。任何真实车辆执行均须依照项目授权与安全流程；无条件时使用仿真或隔离台架。
