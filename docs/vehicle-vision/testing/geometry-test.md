# 视觉坐标与几何测试

## 契约冻结

先记录像素、相机、车辆、世界和 BEV 坐标系的原点、轴方向、单位及变换方向。测试数据需有可测量的标定板、地面点或目标距离作为参考，并明确时间对齐。

## 数值检查

用已知点验证投影/反投影、外参逆矩阵、单位换算、裁剪缩放映射和无效深度处理。报告平面位置误差随距离/方位的变化，而不是只给一个全局平均。

## 端到端检查

在图像或 BEV 叠加坐标轴、网格和关键点，识别左右翻转、轴交换、尺度错误、标定漂移和时间错配。不同模块对矩阵乘法顺序和行/列向量约定必须一致。

## 练习与验收

使用合成点和实测控制点分别验证几何链路。注入一个小角度外参偏差，观察误差随距离增长的趋势并设定告警阈值。

## 参考点与误差预算

为图像像素、相机、车辆和 BEV 选取一组独立控制点，记录测量工具、精度、坐标原点和时间。先用合成点验证矩阵方向与逆变换，再用实测点检查标定和投影；把裁剪、resize、letterbox 和畸变校正纳入同一变换链。

**验收产物：**按距离、方位和画面位置报告投影误差向量及分位数，附轴向可视化和输入配置。分别注入轴交换、左右镜像、单位误用和小角度外参偏差，确认测试能指出错误类型，而非只给一个超差结论。
