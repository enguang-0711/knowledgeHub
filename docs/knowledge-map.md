# 知识地图与内容范围

本站是一套**软件测试与质量工程**学习知识库。知识地图分为可跨行业复用的工程主干、针对具体系统的领域专题，以及供学习和实践复用的知识资产。某个领域写得较深，只代表它是当前案例，不代表整个知识库只服务于该领域。

## 一、通用测试与质量工程

这些主题描述大多数软件/智能系统项目都需要的测试能力。

| 子主题 | 学什么 | 当前入口/状态 |
|---|---|---|
| 测试分析与设计 | 需求拆解、风险识别、边界值、等价类、状态与场景覆盖 | [通用学习路线](/roadmap)，基础内容待继续扩写 |
| 测试开发 | Python 项目结构、pytest、Robot Framework、适配器与数据驱动 | [自动化工程框架](/automation-framework) |
| 质量度量 | 指标定义、分母、样本、趋势、基线与统计陷阱 | 现有指标页以语音系统为例，通用指标章节持续补充：[质量指标](/metrics) |
| 测试平台与 CI | 测试分层、流水线、工件、失败分类、趋势和门禁 | [CI 与质量趋势](/ci-quality) |
| 可观测性与证据 | 日志、事件、界面、设备状态及多种证据的关联 | 现有案例偏车载：[多模态断言](/multimodal-assertions) |
| AI 应用测试 | 生成、检索、评测集、裁判模型、数据治理和人工审核 | [大模型应用测试](/llm-testing) |

## 二、行业与系统专题

每个专题应先说明系统本身，再列出特有术语、数据、硬件接口、风险和验收方式。专题会复用通用工程主干，不另建一套互不兼容的测试基本功。

### 领域案例：车载语音自动化测试

这是当前收录的一个领域案例，细分页面覆盖声学输入、唤醒、ASR/NLU、多轮对话、业务执行、HMI、车辆信号和 HIL。进入[案例导览](/vehicle-voice-testing)，按[专项学习路线](/vehicle-voice-roadmap)逐步学习。

### 后续可建设方向

API/服务测试、Web 与移动端测试、性能与可靠性、安全与隐私、数据与机器学习系统测试等。它们是候选方向，只有在补齐正文、例子和验收练习后才会标记为已建设专题。

## 三、项目与知识资产

- [实战项目](/projects)：把领域知识组合成从输入、执行、断言到报告的可验收练习。当前项目以车载语音为例。
- [模板与检查清单](/templates)：测试用例、实验记录、缺陷报告、数据和发布检查。
- [术语词典](/glossary)：跨主题术语，标注领域上下文和易混点。
- [工具与资料](/tools-and-resources)：按任务选择工具并优先链接官方文档。
- [知识库建设方案](/knowledge-base-plan)：内容分阶段建设、质量审核和发布流程。

## 内容成熟度标记

- **基础已具备**：有连贯解释和可用入口，仍可能缺少通用实例或练习。
- **专题已展开**：有领域系统说明、重难点和分层练习。
- **规划中**：只有范围和候选方向，不能当作已发布的教学内容。

页面的成熟度以正文、来源和练习是否齐备为准；导航中的分类只是入口，不代表该分类的每项内容都已完整。
