## 这份知识库要解决什么问题

高级车载语音测试的对象是一个有声学、算法、对话状态、车机软件和车辆信号参与的系统。一次完整用例至少要说明：输入的是什么声音、声音如何到达麦克风、系统输出了什么理解、触发了什么业务，以及如何独立证明车辆或 HMI 到达了预期状态。

本库的主线是：

> **定义场景 → 固化语料与环境 → 注入音频 → 采集分层证据 → 判定结果 → 归因与趋势分析 → 反馈 CI 和知识资产**

## 建议的学习顺序

1. 阅读[学习路线](/roadmap)，选择阶段并完成对应的可验收产物。
2. 阅读[端到端架构](/architecture)与[质量指标](/metrics)，统一系统边界和统计口径。
3. 完成音频、语料、ASR/NLU、车机集成等基础模块。
4. 用[实战项目](/projects)把离线评测、设备注入和 CI 串起来。
5. 最后引入[大模型辅助测试](/llm-testing)，并保留确定性的主断言路径。

## 推荐的终局能力

给定一条需求和一个车机软件版本，能够设计覆盖正常、边界、多轮、声学干扰及回归风险的场景；生成并追踪可复现的音频资产；在台架或 HIL 环境执行；使用 ASR/NLU、日志、UI 和车辆信号的分层证据判定；将失败聚类并形成可追踪报告；在 CI 中监控准确率、时延、稳定性和环境漂移。
