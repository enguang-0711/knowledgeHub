# 语料资产与 TTS 反向注入

语料是长期测试资产，应像代码一样可版本化、可审查、可追溯。把文本变成音频只是其中一步；每个文件必须能回答由谁/什么生成、使用什么设置、期望系统怎样响应、可在哪些场景使用。

## 语料分层

- **黄金回归集**：规模小、变更受控、人工核验，主分支/每个构建运行。
- **覆盖扩展集**：同义表达、实体、数字、口语、方言/口音和更多声学条件，夜间或按需执行。
- **探索/压力集**：长音频、多轮、噪声、长时间稳定性；结果不一定作为每次提交的硬门槛。
- **安全/拒识集**：无关指令、歧义、非法/危险槽值、重叠说话和误唤醒负样本，隔离授权环境执行。

**本知识点学习卡**

- **先修：**测试集、回归集、覆盖与风险分层。
- **重难点：**黄金回归集需稳定且独立；探索数据和模型调参数据不可悄悄混入验收集。

## 每条数据建议字段

| 字段 | 示例/说明 |
|---|---|
| `case_id` | 稳定 ID，不用文本本身做主键 |
| `utterance` / `reference_text` | 实际表达与规范参考文本分开存 |
| `locale`, `accent`, `speaker_type` | 语言/口音/合成或真人；避免无依据给人群贴标签 |
| `intent`, `slots`, `context_id` | 期望语义及多轮前置状态 |
| `audio_uri`, `sha256` | 音频位置与内容哈希 |
| `sample_rate`, `channels`, `format`, `duration_ms` | 文件技术属性 |
| `tts_engine`, `voice`, `engine_version`, `parameters` | 合成引擎和参数；真人录音写采集设备/授权来源 |
| `noise_profile`, `playback_zone`, `level_calibration` | 声学派生条件及播放位置/电平校准 |
| `expected_events`, `expected_vehicle_state`, `expected_hmi` | 分层期望与断言策略 |
| `labels`, `severity`, `split`, `owner`, `license` | 标签、严重度、数据切分、责任人及使用许可 |

**本知识点学习卡**

- **先修：**结构化数据、schema 和数据血缘。
- **重难点：**文本、音频、标签、合成参数、授权和版本需能关联；缺字段要显式拒绝，不能静默补默认值。

## TTS 生成与复现

每次生成记录引擎名称和 API/模型版本、音色 ID、语言、语速、音高/风格、SSML、参数、请求时间、源文本规范化版本、输出格式和文件哈希。托管 TTS 服务可能更新底层模型；仅记录“edge-tts”或服务名称通常不足以重现完全相同的波形。将生成音频固化为资产，不要在每次测试运行时无版本地重新请求在线 TTS。

采用 TTS 的价值是覆盖规模、参数变体和可快速再生成。其局限是发音人和韵律分布与真人不同，不能用单一合成器推断真实用户泛化。保留人工校验和代表性真人集；真人数据需有合法来源、明确授权、用途限制和删除策略。

**本知识点学习卡**

- **先修：**TTS、SSML、语音采样参数。
- **重难点：**在线模型可能漂移；固化生成音频和参数。合成语音可以扩大覆盖，不能替代真人分布验证。

## 数据切分与防泄漏

对模型评测，测试集与开发调参集隔离；相同句子、近重复表达、同一发音人/录音条件可能造成泄漏。根据目标选择按文本、说话人、噪声录音或时间切分，并报告切分依据。黄金回归集可以跨版本保持不变，但用于训练的语料不能无意并入独立评测集。

**本知识点学习卡**

- **先修：**训练/验证/测试切分和近重复检测。
- **重难点：**同一说话人、相似句式或同一噪声底可能跨切分泄漏；按目标选择按说话人/文本/时间切分。

## 同义表达生成

生成候选后按三层筛选：

1. **语言层**：语法、口语自然度、方言标签准确性。
2. **语义层**：意图与槽位值必须保持；否定、比较、范围和单位含义不能漂移。
3. **测试层**：确保新增样本覆盖未覆盖的现象，避免只增加表面改写。

LLM 可以提供候选，但不能自行确认测试预期。对每个候选保留生成提示、模型版本、审核者和审核结论。

**本知识点学习卡**

- **先修：**语义等价、意图槽位标注。
- **重难点：**表面改写可能改变否定、数值、单位和执行对象；LLM 只能提候选，产品语义必须经规则/人工审查。

## 推荐资产布局

```text
corpus/
  manifest.yaml          # 数据集版本、说明、授权和字段 schema 版本
  cases/
    climate-basic.yaml   # 用例元数据和预期语义
  audio/
    sha256-prefix.wav    # 文件名可用内容哈希或稳定 ID
  noise/                 # 获准使用的噪声资产及来源说明
  reports/               # 生成与审核记录，不混放客户运行日志
```

大文件适合 Git LFS 或受控制品存储；公开 Pages 仓库只放可公开分发的音频。客户录音、身份信息、设备凭证和内部日志不得因为“方便示例”而进入公开仓库。

**本知识点学习卡**

- **先修：**文件系统、内容哈希、数据清单和 Git 大文件存储概念。
- **重难点：**manifest 描述的是资产来源和版本，不是权限本身；公开仓库只放许可清楚的资产，派生文件要能回溯到父文件和处理参数。
