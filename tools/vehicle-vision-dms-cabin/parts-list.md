# DMS 驾驶员监测试验台：概念与实体清单

场景映射：一套开放式座舱切面展示座椅、驾驶员、方向盘、仪表台和近红外 DMS 相机。座椅滑轨改变眼睛到相机的几何距离；场景按钮标出正常注视、视线偏离、闭眼和镜头遮挡四类输入，显示器同步给出对应状态。视线/眼睑状态是选定的教学标签，不代表算法分类或触发阈值。
