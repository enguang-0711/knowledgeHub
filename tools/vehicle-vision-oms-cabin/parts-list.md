# OMS 多座位占用与遮挡试验台：概念与实体清单

**概念：**一排三座的开放式座舱固定在测试底架上，顶置传感器横梁观察三个座位区域；选择一个座位并切换输入标签，样本实体随之移动，控制台显示各座位的标签或无效状态。空座、成人、儿童座椅、空座物品、遮挡和传感器无效均作为预先指定的教学输入，不宣称检测结果。

3. 地板检修盖板（1），底架紧固标记为图形线与圆点
4. 三组纵向座椅导轨与滑块（12）
5. 三组座椅升降支座与枢轴（6）
6. 三组坐垫框、软垫与前沿侧翼（12）

8. 三组头枕外壳（3）
